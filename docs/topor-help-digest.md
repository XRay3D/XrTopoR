## 0. Общая модель системы TopoR

### 0.1. Что такое TopoR по собственному определению

- «TopoR (**Topo**logical **R**outer) — высокопроизводительный, не имеющий аналогов топологический трассировщик печатных плат и высокоэффективный PCB-редактор».
- Ключевые отличия, заявленные справкой:
  - высокая скорость и качество трассировки;
  - **отсутствие преимущественных направлений трассировки в слоях** (нет H/V-слоёв) → меньше параллельных трасс, меньше перекрёстных помех;
  - автопроцедуры редактора: «вычисление наилучшей геометрической формы проводников по топологическим путям» и «перемещение компонентов на разведённой плате без потери имеющейся разводки».
- Исторический контекст («История версий»): работы начаты в 1988 г., когда «grid based router и shape based router, последовательная прокладка проводников с фиксацией их геометрии — исчерпали возможности своего развития». Метод **гибкой трассировки** «отличается от других методов отсутствием жёсткой фиксации каждой из прокладываемых трасс». Первая Windows-версия — 2001 г.
- TopoR **не является сквозной САПР**: нет редактора библиотек/корпусов и схемного редактора; нельзя заменить корпус, добавить компонент. Можно (с 6.2) редактировать **состав цепей** (netlist) и переназначать цепь контакта. Добавление/удаление компонентов — только во внешней САПР с последующим импортом или синхронизацией.

### 0.2. Фундаментальное разделение: топология vs геометрия

Это самое важное для понимания всех остальных разделов.

- Проводник в TopoR задаётся **топологическим маршрутом** (с какой стороны какого препятствия он проходит), а не координатами сегментов. «В TopoR нет необходимости заботиться о точной геометрии проложенного проводника и о соблюдении конструкторско-технологических ограничений — достаточно задать его топологический маршрут».
- Геометрическая форма вычисляется автопроцедурой **«Расчёт формы проводников» (F5)** из топологии с учётом правил зазоров/ширин. Три варианта формы: **Any-angle** (ломаные, ранее «без использования дуг»), **С дугами**, **Под 45°** (новое в 7.0).
- При ручном редактировании «все касания прокладываемого проводника с другими элементами не считаются ошибками. Ошибками не является также чётное число пересечений с другими проводниками, если между ними отсутствуют элементы топологии. Эти пересечения автоматически устраняются при расчёте формы проводников (F5)».
- **Топологическими нарушениями** считаются ровно две вещи:
  - нечётное число пересечений проводника с другим проводником в том же слое;
  - пересечение проводником **центра контакта**, принадлежащего другой цепи.
- Автотрассировщик «разводит все связи, даже если для этого приходится нарушать некоторые технологические ограничения» (100% разводка сразу, DRC-нарушения устраняются потом подвижкой/перекладкой).
- Точность системы: **0.1 мкм**; координаты хранятся с **4 знаками после запятой** (в мм) — OrCad с 5 знаками округляется и даёт ложные «неразведённые» цепи при обратном импорте.

### 0.3. Этапы работы (справка «Начало работы»)

1. Редактирование параметров (однократно).
2. Автоматическая трассировка.
3. Ручное редактирование топологии.
4. Проверка соблюдения проектных норм (DRC).
5. Вывод результатов.

Этапы 2–4 повторяются до приемлемого результата. Рекомендуемый итеративный цикл (FAQ, «Краткая методика»): начальное размещение → трассировка → выявление мест скученности трасс и ПО → изменение размещения → повторная трассировка.

### 0.4. Проект и файлы

| Расширение | Назначение |
|---|---|
| `.fsproj` | файл проекта (формат проекта v2 с версии 6.3; обновление «Обновить формат» необратимо) |
| `.fsx` | дизайн печатной платы (бинарный рабочий формат; открывается только текущей и новой версиями, сохраняется только в новом формате) |
| `.fsb` | сохранённый вариант автотрассировки (можно открыть в редакторе, можно «Продолжить автотрассировку») |
| `.fst` | TopoR PCB — открытый текстовый XML-формат обмена (версия 1.2.0 по разделу «О формате TopoR PCB»; FAQ упоминает 1.1.4; 6.0/6.1 — 1.1.2) |
| `.eco` | ECO-файл для обратной синхронизации |
| `drc.log` | отчёт DRC по умолчанию, в рабочей папке проекта |

- Проект содержит разделы **«Документы»** (ранее «Печатные платы»; любые файлы и папки) и **«Варианты автотрассировки»** (только `.fsb`). Текущий файл выделяется жирным.
- Контекстное меню файла: «Открыть», «Продолжить автотрассировку» (только `.fsb`; «все параметры автотрассировки остаются такими же, как и при получении данного варианта»), «Исключить из проекта», «Удалить с диска» (в корзину), «Показать в папке», «Переименовать», «Свойства».
- Сортировка: папки выше файлов; внутри папок `.fsx` выше остальных; по имени (по умолчанию) или по дате изменения.
- Вкладка **«История»** — ранее открытые проекты по дате.
- **Автосохранение** («Восстановление данных»): автосохранение `.fsx` работает всегда для открытого проекта; автосохранение трассировки включается при запуске автотрассировки. При открытии после сбоя сравнивается время файла автосохранения с основным — если новее, предлагается восстановление (отдельно для дизайна и для автотрассировки). После нормального закрытия временные данные удаляются.
- **Единицы**: с 6.2 единицы импортируемого дизайна берутся из файла автоматически; настройка единиц в «Настройки программы» действует только для новых дизайнов. Переключение мм/мил — вкладка «Настройки» окна управления видимостью.

### 0.5. Лицензии и ограничения (кратко)

- Число сигнальных слоёв: **2 / 4 / 8 / 32** (TopoR 2L/4L/8L/UN). Ограничение действует **только для автотрассировки**; для ручной работы сигнальных слоёв может быть больше. Общее число металлических (сигнальных + опорных) слоёв — до 32 независимо от версии.
- Lite/пробная версия: полнофункциональна, до **8 сигнальных слоёв**, 3 месяца.
- Защита Guardant (аппаратный Sign / программный SP). Linux — только Lite под Wine.

## 1. Параметры дизайна — Редактор параметров (Дизайн > Редактор параметров, F4)

Окно: **Панель навигации** (список разделов) + **Рабочая область** + **Окно сообщений**. Кнопки **Применить** (изменения вступают в силу, окно не закрывается, в файл не пишутся — нужно сохранить дизайн), **Сбросить**, **Закрыть**, **Импорт** (копирование параметров из другого `.fsx`/`.fst`). Редактор параметров можно держать открытым параллельно с редактированием топологии. История откатов редактора топологии отделена от редактора параметров (с 6.0). Изменённые разделы помечаются.

### 1.1. Импорт параметров (кнопка «Импорт»)

Копируются: группы цепей, группы компонентов, группы слоёв, группы сигналов, правила ширины проводников, правила зазоров между проводниками, правила зазоров между компонентами, назначения типов ПО, цепи опорных слоёв, назначение цепей на слои, свойства цепей, правила зазоров до края платы, сигналы (с заданными связями), волновые сопротивления, правила выравнивания в группе, правила взаимного выравнивания, информация о толщинах слоёв. **Все текущие параметры удаляются** (включая правила ширины, которых нет в файле-источнике).

### 1.2. Слои (панель «Слои»)

- Две вкладки: **«Стек слоёв»** и **«Документирующие слои»**.
- Таблица: имя, тип, толщина. Кнопки: создать слой, удалить, переместить вверх/вниз. Визуализация стека — равномерная или пропорциональная толщинам («Переключить отображение стека слоёв»).
- Типы слоёв, упоминаемые в справке: сигнальный, опорный (металлические), механические (верхние/нижние), документирующий, **«Паяльная паста»** (Paste Top/Bottom), **«Маска»** (Mask Top/Bottom), шелкография (ярлыки/надписи «на верхней и нижней сторонах размещения»).
- Флаг **«Учитывать при размещении»** для механических слоёв: очертания компонентов и прочие примитивы этого слоя учитываются при авторазмещении и при автоматической/ручной подвижке (важно: без него компоненты при подвижке F7 «наезжают» друг на друга — см. однослойный сценарий).
- Горячие клавиши активного металлического слоя: `[1..9]` — слои 1..9, `0` — нижний металлический слой; `~`/`` ` `` — вкл/выкл все металлические слои; `Shift+S` — только активный слой.

### 1.3. Контактные площадки — стеки КП (панель «Контактные площадки»)

- Таблица: название стека, размер отверстия, формы и размеры КП по слоям (для многоугольных — охватывающий прямоугольник). Команды: **Изменить**, **Создать новый стек КП**, **Удалить выбранный стек КП**, **Дополнительно** → «Удалить неиспользуемые стеки», «Создать детали на...» (маска/паста).
- Тип стека: **сквозной**, **планарный**, **монтажное отверстие**. Для непланарных — диаметр отверстия. «Каждый тип контактной площадки должен определять либо сквозной, либо планарный контакт. Компоненты могут иметь одновременно и планарные, и сквозные контакты».
- Детали КП **однодетальные** на каждом слое/группе слоёв. Детали создаются либо на «фиолетовых строчках» (типовая деталь для класса слоёв: паста, маска, сигнальный, опорный), либо на «жёлтых строчках» (конкретный слой — когда внутренние слои отличаются от внешних).
- В редакторе стека задаются: имя и свойства КП; **свойства термобарьера**; имена и свойства классов слоёв; имена и свойства слоёв; форма КП для группы слоёв и для каждого слоя.
- **Шесть форм КП**: круг, овал, прямоугольник (квадрат), прямоугольник со скруглёнными углами, прямоугольник со срезанными углами, многоугольник (полигон).
  - **Круг** — диаметр + смещение центра относительно точки привязки.
  - **Овал** — «фигура, полученная перемещением круга вдоль линии»; диаметр (ширина) + «Вытягивание» по X и по Y (направление оси овала = соотношение вытянутостей; произвольный наклон допускается); смещения центра по осям; центр контакта должен лежать на оси овала. Если один стек используется компонентами в противоречивых ориентациях — надо завести разные стеки.
  - **Прямоугольники** (в т.ч. со скруглёнными/срезанными углами) — ширина, длина, смещение центра по X/Y; тип обработки углов **скругление** или **срез** (один тип для всех углов), величина (радиус / срез); флаг **custom** — обрабатывать только отмеченные углы. **Finger pad** = скруглённые углы с радиусом = половине ширины.
  - **Многоугольник** — координаты вершин в таблице или в графическом редакторе (синхронно).
- При вращении компонента КП вращаются вместе с ним.

### 1.4. Переходные отверстия — типы ПО (панель «Переходные отверстия»)

- Таблица: **название**, **диапазон слоёв** (сквозные/слепые), **диаметр контактной площадки**, **диаметр отверстия**, **флажок разрешения перехода на контактной площадке** (via-in-pad).
- Кнопка «Создать новый тип ПО» копирует выделенную строку. Доп. окно **«Диаметр площадки переходного отверстия»** — разные диаметры на каждом сигнальном/механическом слое (тогда поле «Диаметр площадки» перечисляет значения и не редактируется).
- По умолчанию трассировщик выбирает ПО **минимально возможного диаметра**; правило «Назначение цепям типов ПО» (см. 1.7) переопределяет это.

### 1.5. Состав цепей (панель «Состав цепей»)

- Редактирование netlist внутри TopoR: удалять контакты из цепи, перемещать в другую цепь, переименовывать цепи, создавать/удалять цепи, добавлять контакты (с 6.3 — на правой панели). Также через свойства контакта: «Цепь: Изменить» → окно **«Изменение цепи»** (фильтр, добавление/удаление цепей; горячая клавиша **Shift+N**).

### 1.6. Группы объектов (цепей, компонентов, слоёв, сигналов)

- Единый интерфейс: **Панель навигации** (дерево групп + спец. элементы **«Все цепи»**, **«Несгруппированные»**, **«Группы»**), панель инструментов (создать/удалить группу; действия над выделенными), **Область просмотра**, **Поле фильтра** (подстрока имени; очищается при смене элемента), **Поле сведений** (количество).
- Действия: **Переместить в группу** (drag), **Добавить в группу** (Ctrl+drag; объект может быть в нескольких группах), **Исключить из группы**, **Исключить из всех групп**, **Сгруппировать**, **Разгруппировать** (объекты уходят в родительскую группу или становятся несгруппированными), переименование через контекстное меню.
- Иерархия: группа может входить **не более чем в одну** группу; группы первого уровня не могут быть вложены. Перетаскивание на «Группы» выносит группу на первый уровень.
- Назначение групп — задание общих правил трассировки.

### 1.7. Правила (раздел «Правила»)

Общий принцип приоритета: **«Порядковый номер правила в таблице определяет его приоритет… Чем больше номер правила, тем выше его приоритет»** (для пересекающихся множеств объектов). Каждое правило имеет: слой или группу слоёв, объект(ы), значения.

1. **Ширина проводников** — **минимальная** и **номинальная** ширина; слой/группа слоёв; применяется к (цепь, группа цепей, все цепи).
   - «Минимальное значение будет использоваться в узких местах (при отсутствии другого пути) или при подходе к контактным площадкам, размер которых меньше ширины проводника».
   - FAQ: «TopoR старается разводить проводники с номинальной шириной (заужает проводники только если другого пути не существует или он имеет существенно большую длину) и минимизирует число сегментов, ширина которых меньше номинальной». Рекомендация: по возможности min = nom.
   - «При автотрассировке игнорируются правила для ширины отдельных проводников, заданные в процессе редактирования. Вместо них используются правила из свойств дизайна» (при трассировке «с нуля»; при дооптимизации варианта — наоборот, сохраняются использованные ширины, в т.ч. ручные).
2. **Зазор между проводниками** — **минимальный** и **номинальный**; объект 1 и объект 2 (цепь / группа цепей / сигнал / группа сигналов); слой/группа слоёв.
   - Минимальный — «для самых узких мест, для прохода между контактами». Номинальный — «везде, где есть возможность раздвинуть проводники». **«Всегда устанавливайте номинальный зазор несколько больше минимального»**; для однослойных плат — в 1,5 раза больше. Это основное средство против «неточностей» формы проводников у плотных планарных КП.
3. **Зазор между компонентами** — номинальный зазор; объекты (компонент / группа компонентов / все компоненты); слой/группа слоёв.
4. **Зазор до края платы** — от компонентов до края и от проводников до края.
5. **Назначение цепям типов ПО** — цепям/группам назначаются один или несколько типов ПО (например, один сквозной и один слепой). Без назначения — минимальный диаметр.
6. **Цепи опорных слоёв** — назначение цепей на опорные (plane) слои (пример: GND → INT_GND). Предупреждение 5048: цепь, назначенная на опорный слой, «останется неразведённой» (подключается через ПО к плоскости).
7. **Назначение цепей на слои** — цепи/группы (группы жирным) назначаются на сигнальные слои; одна цепь — на несколько слоёв. Список доступного зависит от уже сделанных назначений. Нарушение — предупреждение 5047 («Участок цепи, назначенной на слой…, проложен на слое…»).
8. **High-speed правила** (волновое сопротивление, выравнивание в группе, взаимное выравнивание) — см. раздел 5.

### 1.8. Фильтр сообщений (Дизайн > Фильтр сообщений)

Режимы «проверять все», «ничего не проверять», «проверять отмеченные» (флаг по категориям). **По умолчанию включена проверка всех пересечений и избыточностей, а быстрая проверка зазоров (Online DRC) отключена.**

### 1.9. Настройки редактирования (Дизайн > Настройки редактирования)

Единственная вкладка **«Ярлыки»**: поведение при вращении компонента — **«Вращать с компонентом»** (90/180/270°) или **«Сохранять угол поворота»**; флаг **«Использовать правила ориентации»** — отдельно для **Горизонтальная** (0/180°) и **Вертикальная** (90/270°) надписей, для верхней и нижней сторон. При повороте на произвольный угол правила ориентации не применяются.

### 1.10. Настройки подсоединения проводников к КП (Дизайн > Настройки подсоединения проводников к КП)

- «+» → выбор **стеков КП** или **отдельных контактов**, для которых разрешено подсоединение проводника **к углам** КП; «Очистить» — снять всё.
- Режим по умолчанию **«Определять автоматически»**: подсоединение к углам разрешается только для **скруглённых или срезанных углов прямоугольников с достаточным радиусом**; **радиус достаточен, если он больше половины ширины подсоединяемого проводника**.
- Следствие для роутера: у обычных прямых углов КП проводник должен выходить через сторону (центр/ось), а у finger-pad может выходить через угол.

## 2. Автоматическая трассировка

### 2.1. Общая модель работы автотрассировщика

- «Полная (на 100%) разводка цепей обеспечивается практически сразу, однако при этом возможны нарушения DRC. В дальнейшем эти нарушения автоматически устраняются. Для повышения качества разводки выполняется процесс **оптимизации**».
- Оптимизация — бесконечный процесс: «TopoR будет продолжать оптимизацию бесконечно, пока не остановить процесс (кнопкой **Остановить**)». Система лишь подсказывает момент остановки сообщением **«Поиск вариантов целесообразно остановить»** (когда долго нет улучшений).
- Оптимизация идёт циклами **«перекладки цепей»**; номер цикла = столбец **Уровень** в таблице вариантов («уровень 1 соответствует первой перекладке»). Рекомендация: **не останавливать, пока Уровень не достигнет 5–10**; и не останавливать, пока варианты активно сохраняются.
- Автотрассировщик **перемещает незафиксированные компоненты**: «при трассировке соединений система TopoR обладает способностью в некоторых пределах перемещать компоненты». Поэтому разъёмы, крепёж и т.п. нужно **фиксировать (F)**. «Незафиксированные компоненты считаются подвижными. Это, в частности, означает (если не включён строгий контроль трассировки), что TopoR не будет ограничивать количество проводников между незафиксированными компонентами, считая, что возможные узкие места будут ликвидированы перемещением компонентов».
- Трассировщик **не меняет сторону установки** компонентов и **не выбирает слой** для планарных компонентов (FAQ).
- **Модель ПО во время оптимизации**: «каждый межслойный переход не локализован в какой-то конкретной точке, а представлен фрагментом проводника (между парой пересечений). Такое представление повышает гибкость трассировки, однако приводит к недооценке размеров ПО, и при их скоплении в узких местах появляются нарушения, не устраняемые простой подвижкой». Поэтому «0» в графе «Нарушений» таблицы вариантов **не гарантирует** отсутствия нарушений после открытия в редакторе.
- Правила берутся из **открытого проекта**, а не из исходного `.pcb`: «Если в исходном .pcb-файле и в открытом проекте заданы различные проектные нормы, то трассировка соединений выполняется по нормам, заданным в проекте».
- При автотрассировке BGA выполняется автоматически (см. 2.7). Дифференциальные сигналы разводятся автоматически (с 6.0), но «застёгивание» делается потом (см. 5.4). BGA-трассировка «с учётом двухполюсников, расположенных под BGA-компонентом» (6.0).
- Многослойная трассировка «улучшена и ускорена» (6.2); «существенно повышено качество многослойной автотрассировки» (6.1).

### 2.2. Панель управления автотрассировкой (Трассировка > Автотрассировка, кнопка «Автотрассировка»)

- До первого запуска — вкладки **«Цепи»** и **«Настройки»**; после запуска добавляется **«Варианты»**.
- Кнопки: **Запустить**, **Остановить**, **Продолжить**, **Открыть в редакторе**, «добавить все варианты в проект» (кнопка/ссылка **«Добавить все варианты в проект»** под таблицей), кнопка разблокировки настроек (пока автотрассировка запущена или остановлена, флаги цепей неактивны — надо сначала закрыть сессию трассировки).
- Условия, при которых кнопка запуска **неактивна** (сообщается про первую из них):
  1. отсутствуют цепи для трассировки;
  2. превышено число сигнальных слоёв (лицензия);
  3. не исправлены ошибки **пересечения контактов** (ошибка 5008 / 3004 в FAQ; лечится фиксацией обоих компонентов, если пересечение контактов одной цепи намеренное);
  4. не исправлены ошибки пересечения проводников в **нетрассируемых** цепях.
- «В случае, когда в выбранных для трассировки цепях соединения для оптимизации отсутствуют, поиск вариантов не производится».
- При запуске (без флага «Продолжить трассировку с текущей конфигурации») **все трассируемые цепи, кроме зафиксированных, автоматически удаляются**. Трассировка > **Удалить разводку** удаляет вообще все проводники, **в том числе зафиксированные** («с чистого листа»).

### 2.3. Вкладка «Цепи»

- Таблица объектов (группы **жирным**, цепи **курсивом**). Четыре кнопки показать/скрыть: группы цепей, дифференциальные сигналы, сигналы, цепи. Фильтр по подстроке имени.
- Столбец **«Трассировать»** — флаг управления трассировкой; на строке группы — для всех цепей группы.
- Индикаторные колонки: наличие разводки (значок контурный = частичная разводка), **зафиксированные** цепи, **гибко зафиксированные** цепи, назначение на **опорный слой**.
- Контекстное меню строки: удалить разводку, зафиксировать/расфиксировать, (гибкая фиксация).
- Сортировка по любому столбцу; группы и несгруппированные цепи сортируются раздельно.

### 2.4. Вкладка «Настройки» — полный список флагов

Секция **«Форма проводников»** (с 6.4; переключатель, три значения):
- **Any-angle** (ранее «без использования дуг») — ломаные под любым углом.
- **С дугами** — «участки дугообразной формы чередуются с прямолинейными отрезками, идущими по касательным»; особенно полезно на платах с высокой плотностью (пример в справке: один и тот же фрагмент без дуг даёт нарушение DRC, с дугами — нет). В имени `.fsb` появляется буква **a**.
- **Под 45°** (новое в 7.0) — «придаёт проводникам форму, напоминающую разводку большинства современных САПР. Однако… такая форма проводников **не является реализацией какого-то альтернативного способа прокладки**». В любой момент F5 пересчитывает в любую из двух других форм. «Пока трассировка проводников под 45° не лишена недочётов».
- Выбранная форма становится текущим подрежимом автопроцедуры «Расчёт формы проводников» при открытии варианта в редакторе.

Секция **основных настроек**:
- **«Соединять планарные контакты напрямую»** — разрешает прямое соединение соседних планарных контактов одного компонента (без выхода проводника наружу).
- **«Переназначать функционально эквивалентные контакты компонентов»** — **по умолчанию выключено**; разрешает pin/gate swap в ходе трассировки (эквивалентность только читается из библиотеки — назначить её в TopoR нельзя). Результат можно увидеть через ECO-файл.
- **«Однослойная трассировка»** с выбором **«на нижнем слое» / «на верхнем слое»** (металлизированный слой); перемычки размещаются на стороне компонентов. По умолчанию — многослойный режим. Рекомендуется вместе с «Ослабленный контроль зазоров» и автоматическим перемещением компонентов. Число переходов в варианте = **удвоенное число перемычек**. Перемычка — «просто кусочек проволоки», специальные чипы-перемычки и ряд допустимых длин не поддерживаются.

Секция **дополнительных настроек**:
- **«Ослабленный контроль зазоров»** (Weak check, буква **w** в имени `.fsb`; иначе Strict check, **s**) — трассировщику «позволяется „не замечать“ нарушения, возникающие между контактами разных (нефиксированных) компонентов», в расчёте на последующую **автоматическую подвижку компонентов (F7)**. Даёт меньшую длину и меньше переходов; **не рекомендуется на плотных платах** (где двигать компоненты некуда). Пример из справки: между компонентами нужно 4 проводника, помещаются 3 — при строгом контроле четвёртый пойдёт в обход или через перемычку; при ослабленном — проложится, компоненты потом раздвинутся.
- **«Использовать имеющуюся разводку в качестве начального варианта»** — стартовать оптимизацию с существующей разводки трассируемых цепей; не рекомендуется на плотных многослойных платах; для однослойных — не ставить.
- **«Не дотягивать проводник до точки привязки полигонального контакта»** — для КП сложной полигональной формы; без флага трассировщик создаёт лишний отросток до точки привязки, который может пересечь соседнюю КП.
- **«Продолжить трассировку с текущей конфигурации»** (упоминается в «Выборочная трассировка») — пока не установлен, все трассируемые нефиксированные цепи удаляются при запуске.
- Кнопка **«По умолчанию»** — все флаги сбрасываются (все выключены).

### 2.5. Вкладка «Варианты» — поиск вариантов, критерии, таблица

**Критерии качества** (в порядке перечисления справки): 1) количество нарушений зазоров; 2) количество переходов; 3) суммарная длина соединений; 4) количество **подрезок** («сужений проводников при проходе в узких местах»).

**Столбцы таблицы вариантов**:
| Столбец | Содержание |
|---|---|
| Имя | `name_LLL-VVV[w|s][a][N].fsb` — name = имя платы, LLL = суммарная длина в мм, VVV = число ПО, w/s = Weak/Strict check, a = разрешены дуги, цифры — уникальность |
| Длина | суммарная длина **несглаженных** соединений («обычно на 10–15% превышает длину, получаемую после сглаживания») |
| Переходов | число ПО |
| Нарушений | число нарушений проектных норм (неполная модель, см. 2.1) |
| Подрезок | число сужений проводников номинальной ширины |
| Таймер | время от запуска до получения варианта |
| Уровень | счётчик цикла перекладки цепей |
| мм/переход | прирост длины на один убранный переход относительно «предыдущего» варианта с тем же числом нарушений |

- Сортировка по умолчанию: **по числу нарушений, затем по возрастанию длины**. У самого короткого варианта «мм/переход» пуст. Можно сортировать по любому столбцу даже во время трассировки.
- **Правила добавления/удаления** (справка: «определяются достаточно сложным алгоритмом», но для большинства ситуаций):
  - **замещение** варианта новым — если новый **лучше по всем** отслеживаемым параметрам (длина, переходы, нарушения, подрезки) — т.е. хранится Парето-фронт;
  - **добавление** — если новый «по какому-то из параметров или по их совокупности оказывается не хуже, чем лучший из ранее найденных».
- **Первый вариант** сохраняется, «когда пройдёт один цикл оптимизации или через **20 секунд** после начала оптимизации». Далее — по мере улучшения. «Варианты, уступающие найденному по всем параметрам, автоматически удаляются».
- Эмпирика выбора: хорошие результаты при соотношении **≈25 мм/переход (1000 мил/переход)**.
- Контекстное меню варианта: **Добавить в проект** (записать на диск; также клик по «+»), **Удалить** (если нет в проекте — удаляется и с диска; восстановить нельзя), **Продолжить** (оптимизация продолжается с этого варианта, не с нуля), **Открыть для редактирования**. Открытие в редакторе автоматически добавляет вариант в проект.
- Продолжение с варианта («дооптимизация») сохраняет **уже использованные правила ширины** (в т.ч. ручные). Полная переразводка с новыми правилами — удалить разводку и запустить заново.
- Статус после открытия: в строке состояния — длина, число переходов, число нарушений; в окне сообщений — координаты и слой каждого нарушения.

### 2.6. Выборочная трассировка и гибкая фиксация

- Режим, когда «поиск оптимума осуществляется только для части проводников». Порядок: выбрать цепи → запустить → отредактировать результат → поставить **гибкую фиксацию** на удовлетворительные цепи → повторить.
- **Гибкая фиксация**: «обеспечивает сохранение **топологии** цепи, не гарантируя при этом сохранение „геометрических“ свойств разводки (проводник может быть переложен чуть выше/ниже/правее/левее)». Фиксирует также расположение переходов.
  - Гибко зафиксированные цепи **не трассируются**; не оттрассированные участки такой цепи **не будут дотрассированы**.
  - При установке гибкой фиксации флаг «Трассировать» снимается автоматически.
  - На гибко зафиксированных проводниках **не выполняется Refine** (оптимизация путей) при автоматическом перемещении компонентов.
  - Включается через контекстное меню («Включить гибкую фиксацию» — для проводника/ПО) или вкладку «Цепи».
- Отличие от «жёсткой» фиксации (F): жёсткая фиксирует геометрию сегментов и ПО, гибкая — только топологию.

### 2.7. Трассировка BGA-компонентов

- Выполняется внутри автотрассировки. Автоматически выбирается **тип ПО минимального размера** (он должен быть назначен хотя бы одному правилу) и **два правила трассировки**: одно для проводников на внешнем слое с контактами, другое для остальных слоёв.
- Поддерживаются BGA с контактами **в узлах прямоугольной сетки**; **не поддерживаются** шахматный порядок и поворот на угол, не кратный 90° (для самой трассировки; расстановка фанаутов, напротив, поддерживает нерегулярные и повёрнутые BGA — см. 5.5).

### 2.8. Сценарий однослойной трассировки (раздел «О работе с однослойными платами») — как эталон полного цикла

1. Проверить правила; **номинальный зазор в 1,5 раза больше минимального**.
2. Контур платы — лучше одним многоугольником, чем набором линий.
3. Задать очертания компонентов; для нестандартных слоёв — флаг «Учитывать при размещении».
4. Разместить и зафиксировать то, что жёстко задано.
5. Автотрассировка > Настройки: «Однослойная трассировка» + слой; «Ослабленный контроль зазоров»; «Использовать дуги» если можно; при необходимости «Переназначать функционально эквивалентные контакты»; «Использовать имеющуюся разводку…» — не ставить.
6. Запустить, ждать пока варианты перестанут активно появляться (~1 минута), остановить.
7. Выбрать вариант с **наименьшим числом переходов** (проще потом добавить перемычку, чем убрать).
8. Открыть; F7 в подрежиме **«Подвижка переходов и компонентов с перекладкой проводников»** — несколько раз.
9. F7 в подрежиме **«Подвижка переходов с перекладкой проводников»** — повторять после каждого ручного редактирования.
10. Ручная правка; перед перестановкой компонента удалить инцидентные проводники — появятся линии связей (netlines).
11. Критичные цепи развести вручную и поставить **Гибкую фиксацию**.
12. Проверить прямизну перемычек.
13. DRC. Пункты 6–13 повторить 5–6 раз («если после первой итерации было 18 перемычек, то после пятой может не остаться ни одной»).

### 2.9. Ошибки, блокирующие автопроцедуры

«При некоторых ошибках (например, топологическом пересечении проводников разных цепей, пересечении проводниками контактов или переходов) запуск автоматических процедур невозможен». Намеренное соединение разных цепей возможно только пересечением **двух зафиксированных** объектов (проводник/область металлизации).

## 3. Геометрия трасс, формы проводников, зазоры и DRC

### 3.1. Три формы проводников и автопроцедура «Расчёт формы проводников» (F5)

- Кнопка на **Панели действий** (верхняя из трёх автопроцедур); два подрежима:
  - **без использования дуг** — «прокладка проводника ломаными линиями»;
  - **с использованием дуг окружностей** — «проводник огибает препятствия по дугам окружностей с необходимым зазором, а с одной дуги на другую переходит вдоль отрезков прямых» (т.е. дуги вокруг препятствий + касательные отрезки между ними; дуга = окружность с центром в препятствии, радиус = радиус препятствия + зазор + полуширина проводника).
- Третий вариант **«Под 45°»** доступен как результат автотрассировки; F5 переводит из него в любую из двух классических форм.
- Подрежим F5 **сохраняется в файле дизайна** (в отличие от подрежимов F6/F7, которые живут только в сеансе).
- Кнопка **«капельки»** (нижняя на панели действий) — переключатель флага формы проводников (предположительно teardrops/плавные вводы в КП): «Нажатие на кнопку меняет состояние флага и одновременно изменяет соответствующим образом форму всех проводников на текущей плате. Состояние переключателя сохраняется в редактируемом дизайне».
- Дуги поддерживаются «в любом режиме работы редактора» (с 6.0). Совместимость: P-CAD до 2004 — дуги кратные 0.1°; OrCad и Specctra — кратные 90°; HyperLynx дуги не понимает → перед экспортом в такие САПР дуги отключить (пересчитать F5 без дуг).
- Ограничение модели: «**Неточное определение оптимальной формы проводника**» — «из-за сложности расчёта на плотных платах могут проявляться некоторые неточности» (обычно у микросхем с мелкими частыми планарными КП). Лечение: (1) сдвинуть любой близкий объект (чаще ПО); (2) добавить рядом запрет трассировки; (3) вручную исправить форму и **зафиксировать** сегмент. Главная профилактика — номинальный зазор > минимального.
- Импортированные дуги из других САПР сохраняются «непосредственно после импорта», но при любом редактировании форма пересчитывается.

### 3.2. Ширина, зазоры, подрезки

- Проводник имеет **номинальную** ширину, в узких местах **заужается** до минимальной — это «подрезка» (counted в таблице вариантов). Трассировщик минимизирует число заужённых сегментов.
- Ширина отдельного сегмента меняется вручную (W / «Изменить ширину проводника» / свойства). Массово: фильтр выделения → только проводники → Ctrl+A → поле ширины в «Свойства проводника».
- Ширина проводников **застёгнутой дифф. пары** меняется только через High-Speed правила > Волновое сопротивление.
- Зазор между областью металлизации и объектами других цепей: если не задан в полигоне — из правил; если у цепи полигона и выкусываемого объекта разные зазоры — **берётся больший**.
- Зазор до края платы — отдельное правило (компоненты и проводники).
- Статусная строка показывает в реальном времени общую длину проводников, число переходов и число нарушений.

### 3.3. Подсоединение проводников к контактным площадкам

- Нормально проводник подводится к **точке привязки** КП (центру). Флаг «Не дотягивать проводник до точки привязки полигонального контакта» отключает это для полигональных КП.
- **Подсоединение к углам** разрешается автоматически для прямоугольников со скруглёнными/срезанными углами при радиусе > половины ширины проводника; вручную — для выбранных стеков/контактов (раздел 1.10).
- «Соединять планарные контакты напрямую» — соседние планарные контакты одного компонента одной цепи соединяются напрямую коротким проводником.
- При подходе к КП меньшей ширины, чем проводник, используется минимальная ширина.
- Переход на КП (via-in-pad) — только если у типа ПО стоит флажок разрешения перехода на контактной площадке; иначе ошибка 5009 «переход лежит на контакте».
- Термобарьеры (в полигонах и в свойствах стека КП): подключение «напрямую или через термобарьер»; «TopoR старается создать у термобарьера **четыре спицы**»; если спиц меньше заданного в правилах — предупреждение 5006. Управляются угол поворота термобарьера, ширина спиц, ширина барьера.

### 3.4. Две модели контроля: онлайн-контроль редактора и DRC по реальной геометрии

- В редакторе контроль «осуществляется на модели и не гарантирует обнаружения всех нарушений». Поэтому финально нужно вызвать **DRC**, «работающую с реальной геометрией».
- **Online DRC** («Быстрая проверка зазоров») по умолчанию выключена в фильтре сообщений; с 6.0 «не показывает лишних нарушений там, где на самом деле нарушений нет». Нарушения показываются **окружностями белого цвета**; клик по окружности подсвечивает конфликтующие элементы и выводит диагностику в окне свойств; двойной клик по сообщению центрирует вид и выделяет объект, «редактирование которого сможет устранить данное нарушение» (6.2). «Прореживание близко расположенных нарушений DRC» (6.1).
- Нарушения у незакреплённых компонентов, пересекающих край платы, — предупреждения 5034–5036 с подсветкой.

### 3.5. Проверка соблюдения проектных норм — DRC (кнопка «DRC», Инструменты > DRC)

- Контекстное меню треугольника у кнопки: **«Удалить DRC сообщения»**, **«Настройки DRC»**.
- Проверяется:
  - **целостность цепей** (неразведённые цепи — 4105);
  - **ширина проводников** (4107 — меньше допустимой);
  - **зазоры между элементами топологии**: контактные площадки, проводники, ПО, барьеры трассировки (запреты), области металлизации, надписи (коды 4001–4104).
- Вкладка **«Объекты»** — выбор проверяемых объектов и **допуск (погрешность)** проверки (перенесён с вкладки «Отчёт» в 7.0).
- Вкладка **«Отчёт»**: файл по умолчанию **`drc.log`** в рабочей папке проекта; можно переименовать; **максимальное число регистрируемых ошибок — 1000** по умолчанию; по достижении проверка прекращается.
- Результат: окно с числом ошибок (при нуле — информационное окно), сообщения в окне сообщений с группировкой по типам и счётчиками в скобках, белые окружности в редакторе.

### 3.7. Топологические ошибки и предупреждения редактора (50xx) — что блокирует автопроцедуры

- **Ошибки** (блокируют автопроцедуры): 5008 пересечение контактов (разных цепей / незадействованных); 5009 переход лежит на контакте; 5010 совпадают координаты переходов разных цепей; 5027 проводник пересекает контакт (в т.ч. «перемычка пересекает контакт» при однослойной); 5028 проводник пересекает переход другой цепи; 5030 проводник пересекает область металлизации другой цепи; 5031 проводник пересекает запрет трассировки (перемычка пересекает компонент); 5032 проводник «пересекается с другими цепями» (нечётное пересечение) / перемычка с перемычкой; 5038 объект вне платы; 5039 конфликт объектов; 5040 проводник пересекается с зафиксированным проводником другой цепи; 5042–5046 пересечения со змейками и проводниками дифф. сигнала; 5049–5054 змейки vs запрет/полигон/контур/змейка; проводник пересекает надпись.
- **Предупреждения**: 5003 цепь содержит **контур** (петлю); 5006 мало спиц у термобарьера; 5007 цепь не разведена; 5011/5012 контакт/переход на контуре платы; 5013/5014 контакт/переход лежит на области металлизации; 5015/5016 полигон пересекает контур/другой полигон; 5017–5022 **зафиксированный** проводник пересекает контакт/переход/контур/полигон/запрет/другой зафиксированный проводник (фиксация переводит ошибку в предупреждение — это и есть механизм намеренного соединения цепей); 5023–5026 контакт/переход/полигон на запрете трассировки; 5034–5036 незакреплённый компонент пересекает контур / запрет размещения / другой компонент (с указанием стороны); 5037 цепь содержит **избыточный переход** («как правило, такой переход можно просто удалить»); 5041 в одной цепи пересекаются контакты; 5047 участок цепи на не назначенном слое; 5048 цепь опорного слоя останется неразведённой; 5056 сигнал не используется в правилах; 5057 ширина проводника сигнала не соответствует правилу Zo.
- 5004 — внутренняя ошибка.

### 3.8. Правила форм объектов с дугами (контуры)

- С 6.3 контуры областей металлизации, запретов, контура платы, вырезов и деталей могут содержать **совместно отрезки и дуги**. В таблице «Форма» у точки задаётся **Arc Angle** в диапазоне **−360…360**: отрицательные — по часовой стрелке, положительные — против; дуга идёт от этой точки к следующей точке контура; центр вычисляется автоматически; «чем меньше величина дуги, тем ближе она к хорде».
- Многоугольник с самопересечениями «не учитывается при трассировке» с предупреждением. Пересекающиеся многоугольники одного слоя/роли не объединяются. Многоугольник < 3 вершин удаляется.

## 4. Ручное редактирование топологии

### 4.1. Панель инструментов редактора (режимы и подрежимы)

Вертикальная панель, по умолчанию слева. Один режим активен. ЛКМ — выбрать режим/текущий подрежим; **ПКМ по кнопке — меню подрежимов**. Выбор подрежима хранится только в сеансе (не в настроечных файлах). **Esc** возвращает в основной режим (исключение: выход из «линейки» возвращает в предыдущий режим).

| Режим | Подрежимы |
|---|---|
| Основной режим (выделение и перемещение) | — |
| Перемещение в режиме **Freestyle** (F8) | без подталкивания и соблюдения зазоров; с подталкиванием переходов; с подталкиванием компонентов и переходов |
| Прокладка (R) | прокладка проводников; прокладка дифф. пар |
| Контур платы | все формы, кроме круга |
| Запрет | все формы |
| Область металлизации | все формы |
| Вырез в области металлизации | многоугольник, прямоугольник, окружность |
| Деталь на механическом слое | все формы |
| Создание надписей | — |
| Создание переходов (V) | одиночный переход; ряд переходов; матрица переходов |
| Переназначения | переназначение выводов; переназначение вентилей |
| Линейка (Ctrl+M) | расстояние между точками; расстояние между объектами |

- **Инструменты многократного действия** (не выходят из режима после действия): Freestyle, прокладка проводников, переназначение выводов, создание переходов, линейка. Остальные (все создания объектов, надписи) — **однократные**; удерживать **Shift** при выборе режима, чтобы сделать многократным.
- Формы примитивов: линия, дуга, круг (залитый), окружность (не залитая), прямоугольник, многоугольник.

### 4.2. Панель действий (автопроцедуры)

Три кнопки-автопроцедуры + переключатель «капельки». ЛКМ — выполнить в текущем подрежиме, ПКМ — выбрать подрежим.

1. **Расчёт формы проводников (F5)** — подрежимы: без дуг / с дугами (см. 3.1). Подрежим хранится в файле дизайна.
2. **Перекладка проводников (F6)** = инструмент **Refine** — подрежимы: **с возможностью переноса проводников на другой слой** / **без возможности смены слоя**.
3. **Подвижка переходов (F7)** = «Подвижка элементов» — три подрежима:
   - (1) переходы двигаются **без перекладки проводников**, компоненты на месте;
   - (2) **подвижка переходов с перекладкой проводников**;
   - (3) **подвижка переходов и компонентов с перекладкой проводников** (распространяется и на компоненты).
   Подрежимы F6/F7 — только на сеанс.
4. **Капельки** — переключатель формы проводников, состояние в дизайне.

#### Refine (F6) — точное поведение
- Мотивация: при автоматической подвижке компонентов и ПО «автоматически изменяется геометрия проводников **без изменения топологического пути**», из-за чего некоторые проводники проложены неоптимально. Refine — «процедура автоматической оптимизации **путей** проводников».
- В подрежиме со сменой слоя «может изменять не только геометрический путь проводника, но и его **слой** (если проводник соединяет **сквозные** контактные площадки и/или переходные отверстия). В ряде случаев это уменьшает число переходов». Особенно эффективно на многослойных платах.
- «**Избыточные (ненужные) переходы, возникшие после применения Refine, удаляются автоматически**» (и в целом с 6.0 — автоматическое удаление переходов, ставших избыточными после автопроцедур).
- Не трогает **гибко зафиксированные** проводники.
- После заливки полигона рекомендуется F6: «участки выбранных цепей, находящиеся внутри металлизированной области, будут удалены».
- FAQ: автопроцедуры с оптимизацией путей могут менять положение и слой проводников, поэтому их используют «в самом начале редактирования, а не при окончательной шлифовке».

#### Подвижка (F7) — точное поведение
- «Процедура, улучшающая расположения переходных отверстий». Компоненты раздвигаются «в узких местах и сдвинутся в свободных»; рекомендуется повторять несколько раз; F7 «имеет смысл повторять после каждого небольшого ручного редактирования».
- Внутри **залитых** полигонов автоматическая подвижка компонентов и ПО **невозможна**.
- Учитывает очертания компонентов на слоях с флагом «Учитывать при размещении».

### 4.3. Режим перемещения Freestyle (F8)

- Применим к платам, разведённым **любым** трассировщиком. «Перемещение компонентов, переходов и **точек ветвления проводников**. Оптимальная форма проводников после каждого перемещения вычисляется автоматически» (с дугами или без — по подрежиму F5).
- «TopoR позволяет перемещать элементы на уже разведённой плате, **сохраняя при этом целостность разводки и соблюдая заданные зазоры**». Цели: уменьшение длины, ликвидация узких мест, уменьшение площади.
- Подрежимы:
  - **Без подталкивания** — перемещение без соблюдения зазоров, другие объекты не подталкиваются; «можно протащить переходное отверстие между контактами микросхемы».
  - **С подталкиванием переходов** — подталкиваются ПО и точки ветвления с соблюдением зазоров.
  - **С подталкиванием компонентов и переходов** — подталкиваются также компоненты.
- «Подвижка элементов выполняется автоматически, переходы и ветвления перемещаются в вычисленные оптимальные положения. Если компонент не должен автоматически перемещаться, его необходимо зафиксировать».
- В Freestyle **нельзя вручную менять форму проводников** — она перестраивается автоматически; топологический путь не меняется («проводники не обойдут контакт с другой стороны»). Многоуровневый откат поддерживается (6.0).
- Рекомендуемый порядок устранения DRC после трассировки с ослабленным контролем (FAQ): Freestyle «с подталкиванием компонентов и переходов» (или только переходов) → большинство нарушений исчезает → остальное вручную → снова автопроцедуры.

### 4.4. Выделение

- Клик — компонент/сегмент; **Ctrl+клик** — добавить объекты разных типов/проводников; **Shift+клик** — добавить сегмент того же проводника.
- **X — «циклическое выделение»**: сегмент → весь проводник → вся цепь (все проводники, контакты, ПО) → снова сегмент. Для дифф. пар: сегмент застёгнутой пары → весь застёгнутый участок → оба проводника пары; обычный сегмент → до застёжки → весь проводник.
- **Выделение окном**: слева направо — только объекты **полностью** внутри; справа налево — все **частично** попавшие. Детали на механических слоях выделяются окном только целиком.
- **Ctrl+A** — всё, доступное фильтру выделения. **Esc** — снять выделение. **Правка > Инвертировать выделение** (без клавиши по умолчанию) — для «оставить меньшую часть, удалить остальное».
- **Фильтр выделения** — 12 независимых флагов типов объектов; ЛКМ — переключить один; **ПКМ — оставить только этот**; «Выбрать все»/«Снять все»; недоступные в текущем режиме типы серые.
- Выделенный сегмент: маркеры (минимум 2 — концы; при увеличении масштаба больше). Перетаскивание маркера — редактирование; перетаскивание сегмента не за маркер — **параллельный перенос**.
- Окно поиска (Ctrl+F): компоненты, цепи, контакты, ПО по типу, сигналы; клик — выделить, двойной клик — центрировать.

### 4.5. Прокладка проводника (режим «Прокладывать проводники», R)

- От примитивов с назначенной цепью: КП, полигоны, переходы, сегменты и точки ветвления. Неразведённые связи показываются линиями связи между **пары ближайших примитивов двух компонент связности**.
- «TopoR автоматически ищет путь проводника в **текущем слое без нарушений**. Если такой путь найден, он отображается **штрих-пунктирной линией**». Принять путь — клавиша **`;`** («Проложить проводник автоматически») — проводник прокладывается автоматически. Если не принять — поиск повторяется от каждой новой точки под курсором.
- **Q — «Выбрать новую цель»**: смена цели, «если путь до новой цели короче, чем до старой».
- Если пути в текущем слое нет — линия связи заменяется **«целеуказателем»** (штриховая до ближайшей точки неподсоединённого фрагмента).
- **Backspace** — отменить последнее действие при прокладке. **L** — смена слоя во время прокладки → автоматически добавляется ПО. Можно закончить прокладку на ПО и ставить ПО до опорного слоя (6.3).
- Касания и чётные пересечения не ошибки — устраняются F5.
- FAQ: ортогональная/сеточная трассировка возможна только вручную с привязкой к сетке (G) и углу (O).

### 4.7. Фиксация проводников и переходов (F) — правила специальных случаев

- Фиксированные проводники рисуются **более тёмным оттенком цвета слоя**; фиксированные ПО — другим цветом (вкладка «Объекты»). Чтобы редактировать — расфиксировать. Фиксация сохраняется во всех режимах, **кроме режима размещения**.
- Выделен проводник, заканчивающийся на ПО:
  - при фиксации фиксируются и проводник, и его концевые переходы;
  - при снятии фиксации — только проводник; состояние переходов не меняется;
  - «если у перехода не остаётся ни одного фиксированного проводника, то фиксация с перехода снимается».
- Выделен переход: смена его состояния не влияет на проводники (допустимо: фиксированный проводник — нефиксированный переход).
- Выделен компонент с зафиксированным проводником: при перемещении форма фиксированного проводника не меняется; **между компонентом и проводником создаётся связующий подвижный проводник**.
- «Если среди выделенных объектов имеются зафиксированные, то перемещение запрещено».
- Зафиксированный компонент (F) — не двигается автотрассировщиком/F7/Freestyle. Фиксация компонентов «оказывает большое влияние на топологию», фиксировать только необходимое.
- Фиксация переводит пересечения из ошибок в предупреждения (5017–5022) → способ намеренно соединить цепи.

### 4.8. Действия с компонентами

- Свойства компонента: вкладки **Общие**, **Контакты** (столбцы **КП** — имя площадки, **ЭК** — эквивалентность контактов, **В** — вентиль, **ЭВ** — эквивалентность вентилей, **П** — перемычки: 1 если два контакта соединены перемычкой), **Атрибуты** (RefDes и PartName неудаляемые; ярлык — отображение атрибута, у атрибута может быть несколько ярлыков; отключённый ярлык не отображается и не экспортируется), **Ярлыки**.
  - Семантика ЭК/В/ЭВ: функционально эквивалентные контакты одного вентиля — одинаковое ЭК; контакты одного вентиля — одинаковое В; контакты функционально эквивалентных вентилей — одинаковое ЭВ.
- Свойства контакта: положение (координаты, угол), стек КП (переход в редактор КП), цепь (изменение).
- **Фиксация** — F. **Смена стороны** — Правка > Сменить сторону компонента. **Повороты**: Повернуть на 90° (**Shift+Space**), на −90° (**Space**), на произвольный угол (диалог «Введите угол»). **Перевороты**: горизонтально (**S**), вертикально (**Y**) — «трёхмерная операция»: компоненты и подсоединённые проводники переходят на симметричный слой (Top → Bottom).
- Центр поворота: «точка, которую TopoR считает центром»; для компонентов без очевидного центра — центр охватывающего прямоугольника (видно при флаге «Габариты» в Объекты > Компоненты). Для нескольких объектов — центр их общего охватывающего прямоугольника. С 7.0 поворот/переворот фрагмента топологии (компоненты вместе с проводниками).
- **Отсоединить** (**U**, Правка > Отсоединить) — отсоединяет проводники от выделенных компонентов перед поворотами/сменой стороны, чтобы проводники не пересекались.
- При смене стороны планарного компонента проводники остаются неподключёнными.

### 4.9. Переназначение функционально эквивалентных контактов (Инструменты > Переназначение выводов; подрежимы «переназначение выводов» / «переназначение вентилей»)

- Каждой группе эквивалентных контактов присваивается буква **[A–Z, a–z]** и один из **6 цветов** (после 6 цветов буква меняется, цвета повторяются).
- Клик по контакту — выделение; второй клик по контакту **той же группы** — обмен: «у контактов меняются номера цепей, проводники, подходившие к контактам, перебрасываются». Если второй клик не по контакту группы — выделение снимается, команда не выполняется.
- Обычно после этого нужно устранить пересечения с контактами; окончательная форма — в Freestyle. Планарные контакты на разных слоях — проводники остаются неподключёнными.
- Изменения переносятся в схему через ECO-файл.

### 4.10. Переходные отверстия в редакторе

- Автоматически — при смене слоя при прокладке. Вручную — **V** (Вставка > Межслойный переход): **Одиночный переход**, **Ряд переходов**, **Матрица переходов**. Окно «Свойства нового перехода»: тип ПО, цепь (фильтр), **зазоры** между переходами в группе (для ряда — только горизонтальный; для матрицы — оба). Ряд: первая точка — центр первого перехода; матрица — угол охватывающего прямоугольника; затем движение мыши и повторный клик; ПКМ — отмена.
- V добавляет тот тип (одиночный/ряд/матрица), который активен на панели.
- Тип ПО меняется в «Свойства перехода» из списка типов дизайна. Контекстное меню — вызов редактора переходных отверстий.
- Избыточные ПО после автопроцедур удаляются автоматически; предупреждение 5037 для избыточного перехода в цепи.
- 5010: совпадают координаты переходов разных цепей — ошибка.

### 4.11. Надписи и стили

- Инструмент «Создать надпись» / Вставка > Надпись → прямоугольник «Text» и панель **Надпись** в окне свойств: текст (Enter применяет), поворот на произвольный угол, **Зеркальность**, стиль, точка привязки и выравнивание, слой (шелкография верх/низ или сигнальные слои), редактор стиля.
- Стиль: **шрифт (растровые шрифты)**, **толщина линии**, **высота символа**. Нельзя удалить используемый стиль и стиль «default» (его можно редактировать). Множественное выделение — общие поля редактируются, точка привязки нет.
- Надписи на сигнальных слоях участвуют в DRC (коды с «надписью»/«ярлыком»).

### 4.12. Контур платы и вырезы

- Инструмент «Создать контур платы» (ПКМ — выбор формы, кроме круга); толщина линии на вкладке «Общие»; координаты точек на вкладке «Форма». Вырез — тот же инструмент, свойство **Роль = «Вырез в контуре платы»**.
- Для однослойных плат: лучше один многоугольник, чем набор линий. При импорте из Altium контур должен быть линиями на Keep-out Layer, не Room.

### 4.13. Запреты (Вставка > Запрет)

- Роль: **запрет трассировки** или **запрет размещения**.
- Запрет размещения: сторона — **Верхняя сторона / Нижняя сторона / Обе стороны**.
- Запрет трассировки: распространяется на **Проводники / Переходные отверстия / Проводники и переходные отверстия**; один или несколько слоёв действия.
- Вкладка «Форма»: правка вершин, добавление вершин/отрезков/дуг (Arc Angle, см. 3.8).
- Из DSN: охватывающий прямоугольник текста приходит как запрет трассировки; из OrCad неподключённая КП → запрет на всех слоях диаметром КП.

### 4.14. Области металлизации (полигоны) — Вставка > Область металлизации

Свойства «Общие»:
- **Цепь** — объекты той же цепи не «выкусываются».
- **Слой** — только сигнальные.
- **Состояние**: **Без заливки** (не учитывается автопроцедурами и DRC; контур редактируем) / **Залита** (объекты других цепей выкусываются с зазором; полигон может распасться на несвязанные части — островки можно выделить и удалить) / **Зафиксирована** (не реагирует на «Перезалить все/выделенное», «Удалить заливку»; если фиксируется незалитая — создаётся залитая область по контуру **без термобарьеров и без выкусывания**).
- **Термобарьеры**: подключение контактов и ПО той же цепи напрямую или через термобарьер; 4 спицы; угол, ширина спиц, ширина барьера.
- **Приоритет**: области с большим приоритетом выкусываются из областей с меньшим; при равенстве — меньшая по площади из большей.
- **Зазор**: по умолчанию из правил; при разных у цепей — больший.
- **Удалять неподключённые островки** (без контактов/ПО/проводников той же цепи); **Минимально допустимая площадь островка**.
- **Точность аппроксимации**: низкая / средняя / высокая (для круглых/изогнутых объектов).
- **Штриховка**: сплошная / сетка / диагональная; **Толщина линий**, **Зазор между линиями**.
- Заливка/отмена — **Z**. Изменение влияющих свойств залитой области → автоматическая перезаливка.
- **Правка > Удалить заливку и восстановить проводники** — удаляет заливку и ищет вариант прокладки для ранее удалённых проводников внутри неё.
- **Вырезы в металлизации** (инструмент «Создать вырез в металлизации»; только при одной выделенной незалитой незафиксированной области; могут перекрываться и выходить за пределы области; Del удаляет).
- Инструменты > Области металлизации: **Залить всё**, **Удалить заливку у всех** (только незафиксированные), **Перезалить всё** (незафиксированные), для выделенных — **Залить выделенные / Удалить заливку у выделенных / Перезалить выделенные**. Свойства островка: **Преобразовать в область металлизации**.
- Правила взаимодействия с трассировщиком (FAQ + «Особенности»):
  - толщина линии полигона ≥ ширины подключаемых проводников;
  - залитый до автотрассировки полигон — непроходим: «ни одна цепь через него не пойдёт», автотрассировщик **не ставит ПО других цепей** в залитой области;
  - полигон, который можно резать проводниками, заливать **после** устранения всех DRC;
  - внутри залитых полигонов нет автоматической подвижки компонентов и ПО;
  - после заливки запустить F6 (Refine); при перемещении цепей/ПО в залитом полигоне — перезалить.
- Авторазмещение имеет функцию удаления заливки всех областей (включая зафиксированные).

### 4.15. Детали на механических слоях

- **Привязка к углу (O)** — сегмент с перемещаемой вершиной выравнивается на угол, кратный **45°**; **P** — переключить, какой из двух инцидентных отрезков выравнивать. **Привязка к сетке (G)**. Состояние в правом углу статусной строки («Grid: off/on», «Any / x45»).
- Линия: клик — вершина; ПКМ/Esc — завершить. Дуга — два способа: **по центру и двум точкам** (центр → начальная точка (радиус) → конечная) и **по трём точкам** (начало → конец → положение центра). Дуга рисуется против часовой стрелки. 4 маркера у дуги: центр (меняет центр/радиус при фиксированных концах, не меняет изгиб), середина (меняет изгиб), концы (с Ctrl — по фиксированному радиусу, с привязкой 45°; без Ctrl — меняется радиус, противоположный маркер скользит по прямой к центру). Круг/окружность: центр → точка; 5 маркеров. Прямоугольник: две вершины, 4 маркера. Многоугольник: клики, ПКМ/Esc.
- Перемещение детали — за контур (не за маркер).

### 4.16. Окно управления видимостью (Alt+D)

- **Слои**: видимость слоёв, отдельно КП / проводники / детали (П/Д) на слое; **активный слой** — «с которого начинается поиск объектов под курсором», рисуется поверх; новые объекты (запреты, полигоны, надписи) создаются на активном слое; «Только активный слой» (Shift+S); клавиши слоёв в квадратных скобках.
- **Схемы**: цветовая схема и схема отображения — выбор, изменение (предопределённые не меняются), создание (ввести новое имя), удаление (только пользовательские).
- **Объекты**: видимость и цвет областей металлизации, монтажных отверстий, связей, ПО, компонентов (флаг «Габариты»), надписей, запретов, нарушений.
- **Настройки**: цвет фона, цвет контура платы, **проводники тонкими линиями** (для разбора скученных мест), область змеек, яркость выделения/затемнение, **единицы** (английские/метрические), привязки к сетке и углу, сетка (точки/линии, цвет, шаг по X/Y, «Сохранять пропорции»; Esc отменяет, Enter сохраняет).
- **Цепи**: «Использовать особый цвет» — списки сигналов/цепей/групп с заданным цветом; **фильтр отображения связей** — для выбранных цепей «показывать связи» или «скрывать связи» (7.0).

### 4.17. Линейка (Ctrl+M)

Режимы: **Расстояние между двумя точками** и **Расстояние между двумя объектами**. Расстояние между объектами — минимум по точкам объектов; для проводника — минимум по всем сегментам. В статусной строке — значение и dx, dy.

### 4.18. Статусная строка и мышь

- Пять частей: (1) общая длина проводников, число переходов, число нарушений — в реальном времени; (2) пусто; (3) координаты курсора после нажатия ЛКМ + смещение относительно последнего нажатия (относительные координаты с 6.2); (4–5) «Grid: off/on» и «Any / x45».
- Мышь: колесо — масштаб; средняя кнопка — панорамирование; ПКМ — контекстное меню / сдвиг рабочей области.

### 4.19. Контекстные меню — соответствие действий и объектов

- Общая часть: Вырезать, Копировать, Дублировать, Вставить, Удалить (del).
- Специфическая часть (действие → объекты): **Выделить всю цепь** — проводник, ПО; **Включить гибкую фиксацию** — проводник, ПО; **Вызов редактора СКП** — контакт компонента, монтажное отверстие, фрипад; **Вызов редактора волновых сопротивлений** — проводник с контролируемым Zo, змейка; **Вызов редактора переходных отверстий** — ПО; **Вызов редактора стилей** — надпись; **Зафиксировать/Расфиксировать** — компонент, монтажное отверстие, фрипад, сегмент (включая фрагменты дифф. пар), змейка, ПО; **Поворот** — компонент, ярлык, область металлизации, вырез, запрет, контур платы, надпись; **Изменить сторону установки** — компонент; **Залить/Перезалить/Удалить заливку** — область металлизации; **Застегнуть, Расстегнуть, Изменить ширину, Изменить слой, Спрямить** — проводник, сегмент, змейка; **Преобразование в змейку** — все проводники; **Преобразование в проводник** — змейки.

### 4.20. Восстановление данных (Recovery) и инвертирование

- Recovery — см. 0.4: автосохранение дизайна всегда, автотрассировки — на время сессии; проверка по времени файлов; два вида уведомлений (дизайн / автотрассировка).
- Инвертирование выделения — Правка > Инвертировать выделение; типичный сценарий: выделить то, что оставить → инвертировать → Del.

## 5. Специальные функции

### 5.1. Сигналы, сигнальные кластеры, дифференциальные сигналы, группы сигналов (High-speed правила > Сигналы)

- **Сигнал** — объект для представления линии передачи: **один источник (контакт) и один приёмник (контакт)**. Несколько сигналов могут иметь общий источник; общего приёмника быть не может.
- **Сигнальный кластер** — «подсхема, содержащая все возможные пути от выбранного источника к приёмникам»; один источник, один или несколько приёмников; цепи кластера — цепи, через которые передаётся сигнал (через **пассивные компоненты** — двухполюсники или двухконтактные вентили с эквивалентными контактами, например резисторные сборки).
- Панель «Сигналы»: интерфейс групп + панель задач (**Создать сигнал, Поиск шин, Поиск дифф. сигналов, Настройки поиска**), панель действий (**Задать топологию, Подсветить, Удалить, Объединить в дифф. сигнал, Разделить**), панель свойств (источник, приёмник, Zo).
- **Создание сигнала** — три шага: выбор источника → определение приёмников → задание топологии цепей.
  - Окно «Выбор источника сигнала»: флажки **«Скрывать пассивные компоненты»**, **«Скрывать цепи, исключённые из поиска сигналов»**, **«Скрывать цепи, включённые в сигналы»**; поиск по нескольким подстрокам через пробел по именам компонентов, контактов, цепей; контакты уже занятых цепей серые с указанием сигнала.
  - Набор цепей кластера строится автоматически: все цепи, связанные с цепью источника через пассивные компоненты, **кроме**: силовых цепей; цепей противофазного сигнала дифф. пары; цепей другого кластера. Ручная коррекция: **Добавить цепь** (через любые компоненты; нельзя силовую и из другого кластера), **Удалить** (нельзя цепь источника и единственное связующее звено). Флаг **«Обновлять автоматически при изменении списка цепей»** / кнопка «Обновить».
  - **Приёмники** — контакты активных компонентов, кроме компонента источника; для каждого создаётся сигнал; если несколько приёмников в одном компоненте — только ближайший к источнику. Можно добавлять сигналы, менять приёмник (любой свободный контакт кластера), переименовывать; дубли имён запрещены.
  - **Задание топологии** цепей с >2 контактами: пары соединяемых контактов (связи); контур → сообщение «В цепи '…' имеется контур, необходимо исправить заданные связи». Флаг «Автоматически задавать связи» — источник соединяется с каждым приёмником.
- **Волновое сопротивление (Zo)** — одинаково для всех сигналов кластера; столбцы Zo задают **ширину проводника на каждом сигнальном слое**; предопределённые **Z0_50** и **Zdiff_100** (неудаляемые). **Значение Zo в 7.0 никак не используется, только информационно; соответствие ширины и Zo не проверяется** (но проверяется соответствие ширины правилу — предупреждение 5057).
- **Дифференциальный сигнал (ДС)**: вручную — выделить два сигнала → «Объединить в дифф. сигнал»; условия: из разных кластеров, одинаковое число цепей, схожие заданные связи. Автоматически — «парные сигналы»: источники и приёмники в тех же компонентах, одинаковое число цепей, имена по правилам именования; флаг **«Объединить все найденные парные сигналы в дифф. сигналы»**; задача «Поиск дифф. сигналов». Параметры ДС: **допустимый разброс длин парных сигналов** (пример 0,254 мм = 10 mil) и Zo. «Разделить» удаляет ДС, оставляя два сигнала. Удаление ДС удаляет и его сигналы.
- **Шины**: сигналы с источниками/приёмниками в тех же компонентах и именами цепей источников, отличающимися **индексом** («произвольная последовательность цифр, возможно в круглых или квадратных скобках») → группы сигналов; флаг «Преобразовать все найденные шины сигналов в группы сигналов»; задача «Поиск шин».
- **Настройки поиска сигналов**: вкладка «Общие» — **Максимальное количество цепей в сигнальном кластере** (при превышении удаляется добавленная и предыдущая цепь, но не цепь источника), **Список силовых цепей** (автозаполнение + ручная правка), **Минимальное количество контактов в силовой цепи** (для автозаполнения), **Автоматически задавать связи**. Вкладка «Дифф. сигналы» — правила именования: две подстроки (одна может быть пустой), имена отличаются только ими **в одной позиции** (пример `p`/`n`: `NetCLKp`/`NetCLKn` ✓, `Net_pCLK`/`Net_nCLK` ✓, `pNetCLK`/`NetCLKn` ✗); порядок = приоритет; флажок отключения.
- Для сигналов/ДС/групп можно задавать правила **зазоров между проводниками** и **назначения типов ПО**; основное назначение — правила синхронизации задержек. Сигнал, не используемый в правилах — предупреждение 5056.
- FAQ: при экспорте в другие САПР сохраняются только сигналы из одной двухконтактной цепи (ДС — из двух двухконтактных); многоконтактные теряются.

### 5.2. High-speed правила: выравнивание в группе и взаимное выравнивание

- **Выравнивание в группе**: таблица правил; **Добавить новое правило** → группа сигналов + **допуск**; флажок отключения; **Удалить правило**. Допуск рекомендуется в **пикосекундах (пс) или наносекундах (нс)**; допускается в единицах длины (не рекомендуется из-за разной погонной задержки по слоям); без явных единиц — текущие единицы длины.
- **Взаимное выравнивание** — два типа правил:
  1. **абсолютное значение задержки** — один объект + столбец **Константа**;
  2. **соотношение**: `−tolerance(−) ≤ Delay(1) − Delay(2) − c ≤ tolerance(+)`, где c — требуемая разность, tolerance(+)/(−) — верхний/нижний допуск; объекты — сигналы или группы сигналов.
  Пример: сигналы трёх групп должны опережать клок на 5…6 пс.
- Пример из справки: разброс внутри дифф. пары задаётся в свойствах ДС (не в правилах); допуск 17 пс между двумя дифф. парами делится пополам на ± допуски; избыточные правила отключают флажком.
- Нарушение правила выравнивания — запись в окне сообщений с именами цепей с наибольшим несоответствием (первой — более короткая) и величиной в **пикосекундах**.

### 5.3. Выравнивание задержек — змейки (ручное и автоматическое)

- Змейка («серпантин») вписывается в **трапецию** (изначально прямоугольник), создаваемую на месте выделенного фрагмента проводника кнопкой **«Преобразовать в змейку»**. Вкладка свойств **«Задержка»**: **зазор между соседними изломами** (**по умолчанию — две ширины проводника**) и **требуемая задержка (длина)**; показывается **диапазон min–max** возможной длины в данной трапеции.
- Маркеры трапеции: на краях оснований — длина основания и угол боковой стороны; центральные маркеры боковых сторон — параллельный перенос боковой стороны; средний маркер основания по перпендикуляру — параллельный перенос основания, с отклонением — поворот трапеции вокруг центрального маркера противоположного основания. Shift — симметрия.
- Если набор трапеций даёт достаточно места — длина выдерживается с точностью **не хуже 50 нм**; иначе — запись о невыполнении правила.
- Повторное нажатие «Преобразовать в змейку» на выделенной трапеции убирает трапецию, змейка остаётся как обычные сегменты проводника.
- **Узкие области** (ширина < периода змейки): змейки постоянной амплитуды **без дуг**; **минимальная ширина области — 1.5 ширины проводника**; при редактировании сплошная линия — область по маркеру, пунктир — реальная область вписывания.
- **Автоматическое выравнивание**: **Инструменты > Создать змейки** — на проводниках, нуждающихся в выравнивании, вписываются змейки нужной длины (если место есть) или максимально возможной.
- Змейки участвуют в DRC/топологических проверках (5042–5053), могут фиксироваться, имеют контекстные действия «Преобразование в проводник», вызов редактора Zo.

### 5.4. Дифференциальные пары — прокладка, застёжки, восстановление

- Режим **Трассировка > Ручная прокладка дифф. пары** (подрежим инструмента прокладки): контакты разных дифф. пар подсвечиваются разными цветами.
- Модель: дифференциальная пара = набор **«застёгнутых» пар проводников** и обычных проводников. Застёгнутая пара — «застёжка-молния с двумя **замками**»; **замок всегда ориентирован перпендикулярно направлению ближайшего к нему сегмента** застёгнутой пары.
- Прокладка: клик по подсвеченному контакту → пара проводников от обоих контактов, сходящихся на заданное расстояние; второй клик — замок под курсором; далее застёгнутая пара прокладывается как единый проводник; у второй пары контактов клик по одному из них ставит замок на конце последнего сегмента и дорисовывает проводники к контактам.
- **Расстегнуть проводники** — кнопка для выделенного участка. **Застегнуть проводники** — выделить цепочки сегментов обоих проводников (Ctrl+клик, X) → кнопка. Застегнуть все пары после автотрассировки: **Ctrl+A → Застегнуть проводники** (могут появиться нарушения — вручную).
- **Требования к застёгиваемым участкам**: проводники принадлежат ДС из правил; **на одном слое**; ширины соответствуют правилу Zo; длина каждого «по воздуху» ≥ **3 × ширина застёгнутой пары** (ширина пары по правилу = **две ширины проводника плюс зазор**). Более короткий участок (по воздуху) удаляется, на месте другого образуется застёгнутая пара.
- Редактирование застёгнутого участка — как обычного проводника (перемещение, спрямление). Ширина — только через High-Speed правила > Волновое сопротивление. Del — удаляет только расстёгнутые участки. **L** — смена слоя: автоматически добавляются застёжка в текущем слое, **пара ПО**, застёжка в новом слое и соединяющие сегменты. **Поменять цепи местами** (в свойствах застёгнутой пары, затем «Применить»; Alt+Space «Переключить цепи у дифференциальной пары») — для устранения перекрещивания.
- **Инструменты > Восстановить дифф. пары проводников**: застёгивает найденные пары; нужны определённые ДС; «гарантируется восстановление всех дифференциальных пар, созданных программой TopoR **с отключенными дугами** и удовлетворяющих правилам ширины и зазора для соответствующих дифф. сигналов на соответствующем слое»; форма проводников не меняется. Сообщения: «Обнаружены и застёгнуты дифф. пары проводников для N дифф. сигналов» / «Дифф. пар, подходящих для восстановления, не обнаружено» / «Нет заданных дифф. сигналов». Назначение — восстановление после round-trip через другую САПР (информация о парах при экспорте теряется).
- Автоматическая разводка дифференциальных сигналов — с 6.0.

### 5.5. Расстановка фанаутов (Инструменты > Расставить фанауты) — новое в 7.0

- Фанаут — ПО, соединённое с рядом стоящей планарной КП. Делается **до автотрассировки**, чтобы КП не блокировались проводниками на одном слое; обеспечивает доступ к планарным контактам на всех слоях (гарантия отсутствия блокировки при достаточном числе слоёв, но не на отдельном слое).
- Для **регулярных BGA** без компонентов на другой стороне фанауты расставляются **от центра по квадрантам**. Для **нерегулярных BGA** — отдельный, более сложный алгоритм. Поддерживаются BGA, повёрнутые на произвольный угол.
- Рекомендуется также у контактов цепей «земли» и «питания».
- Производительность из справки: **4471 переход за ~3 секунды** (вручную — дни/недели).
- Пример блокировки: без фанаутов на слое из внутренней области выведены 4 проводника вместо возможных 28 (7 каналов × 4 стороны).

### 5.6. Полигональная разводка (Инструменты > Преобразовать проводники в обл. металлизации)

- Для силовых плат: окно **«Преобразование проводников в полигоны»** — выбор цепей, либо переключатель **«Все проводники на слое»** с выбором слоёв; кнопка **Преобразовать**; откат Ctrl+Z. Проводники превращаются в области металлизации (полигоны).

### 5.7. Авторазмещение (Инструменты > Авторазмещение; с 6.1)

- Алгоритм: **силовой** (force-directed) — оптимальное положение каждого компонента по критерию минимальной длины соединений; затем **раздвижка** «на основе последовательного **дихотомического разбиения пространства** с назначением групп компонентов в области разбиения» до тех пор, пока в каждой области не окажется один компонент (размеры областей пропорциональны сумме площадей компонентов); каждая итерация стартует с координат предыдущей; **лучший по длине вариант запоминается**.
- Признанные недостатки: фактически в один слой (минимум пересечений проекций); не учитывает запретные зоны внутри области; нет кластеризации (развязочные конденсаторы сбиваются в отдельную группу); возможны перекрытия из-за разных габаритов; область размещения = минимальный прямоугольник вокруг всех компонентов (не проверяется, что компоненты на плате); сторона установки не меняется; произвольный поворот не делается.
- Запуск только при наличии хотя бы одного незафиксированного компонента; **вся имеющаяся разводка удаляется автоматически**. Окно показывает текущую длину связей, время, напоминание о ручной остановке; пауза → продолжить или вспомогательные операции (рассчитать область размещения, перенести все компоненты внутрь области, удалить заливку всех полигонов включая зафиксированные). Предупреждение «В области размещения нет ни одного компонента».
- Пример 2: длина связей с 367.5 до 307.7 см. На время работы блокируется почти весь UI, кроме раздела Вид.

### 5.8. Слои маски и пасты

- Служебные слои **Paste Top/Bottom** (тип «Паяльная паста») и **Mask Top/Bottom** (тип «Маска»). Детали создаются из панели КП («Создать детали на...» → Mask или Paste), для одного или нескольких стеков; выбор слоя (Top, Bottom, оба), действие с существующими (заменить/пропустить), **отступ** по слоям. Таблица TM/BM/TP/BP показывает наличие и перезапись.
- **Маска: отступ наружу** (деталь больше КП). **Паста: отступ внутрь** (деталь меньше КП, «чтобы паста не выступала за пределы КП»).
- DSN не передаёт маску/пасту — перед Gerber их надо создать.

## 6. Форматы, импорт/экспорт, выходные файлы, синхронизация

### 6.1. TopoR PCB (`.fst`) и собственные форматы

- **TopoR PCB** — «открытый текстовый формат описания дизайнов печатных плат… создан на основе стандарта **XML** и предназначен для переноса проектов на новые версии программы, а также для обмена данными с другими САПР». Версии: 1.1.2 (6.0/6.1), 1.1.4 (FAQ), **1.2.0** («О формате TopoR PCB», 7.0); документ «Описание формата Topor PCB 1.2» — на eda.eremex.ru/downloads. Новые версии не читаются старыми TopoR (6.3 → только ≥6.3).
- Что заведомо содержит `.fst` (по списку импорта параметров и синхронизируемых объектов): стек слоёв с толщинами; стеки КП; типы ПО; состав цепей; компоненты (посадочные места, атрибуты, UniqueId), схемные компоненты (выводы, эквивалентность), фрипады, монтажные отверстия; группы цепей/компонентов/слоёв/сигналов; все правила; сигналы, ДС, Zo, правила выравнивания; проводники (с дугами), ПО, полигоны, запреты, надписи, ярлыки, детали.
- `.fsx` — рабочий бинарный; совместимость: 6.2 открывает `.fsx` с 6.0; переносимость между версиями 5.2 → 6.0 только через `.fst`. 6.0 → 6.1 `.fsx` теряет прокрутку/масштаб/цвета/видимость.
- Единицы хранения — 0.1 мкм точность, 4 знака после запятой в мм.

### 6.2. Поддерживаемые форматы

**Импорт** (Файл > Импорт, Мастер импорта; кнопка «Настройки» для форматов с опциями): Specctra `.dsn` (Specctra/Electra); PCAD ASCII PCB `.pcb` (P-CAD 2000–2006); PADS ASCII PCB `.asc` (PADS 3.5–2005.1); Expedition `.hkp` (2005–2007); Eagle `.brd`; TopoR PCB `.fst`. После импорта: «Добавить документ в текущий проект» или «Создать новый проект».

**Экспорт** (Файл > Экспорт > Экспорт дизайна, Мастер экспорта: формат, имя файла, **файл-прототип**): TopoR PCB `.fst`; Eagle `.brd`; PCAD ASCII PCB `.pcb` (2000/2002/2004/2006); PADS ASCII (3.5/4.0/5.0/2005.0); Specctra/Electra `.ses`; Expedition `.hkp` (Expedition 2005).

- «В штатном режиме TopoR экспортирует только те данные, которые сам использует» → можно импортировать `.dsn`, экспортировать `.pcb`/`.hkp`, но с потерями. **Экспорт по прототипу** (тот же формат на входе и выходе) позволяет вывести и то, что TopoR не использует.
- Только вывод: Gerber 274X, Excellon drill, DXF, BOM, ECO, печать.

### 6.3. Особенности `.ses` по целевым САПР (при экспорте нужно указать САПР)

| САПР | Кавычки | Читает координаты компонентов из .ses | Единицы | Дуги в .ses | Via «signal» (одна КП на всех слоях) | Прочее |

| PCAD | одинарные | да | только метрические | нет (хотя сам P-CAD дуги умеет) | да | требует префикс **CCTVIA** у переходов |
| DipTrace | одинарные | да | метрические и английские | **да (единственный)** | да | разделитель «.» vs локаль Windows с «,» |
| OrCad | одинарные | да | метрические и английские | нет | нет (КП на каждом слое) | |
| Proteus | двойные | **нет** | только метрические | нет | да | компоненты в TopoR не двигать |
| KiCad | двойные | да | только метрические | нет | нет | |
| Pulsonix | двойные | **нет** | только английские | нет | нет | компоненты не двигать |
| Altium | нет кавычек | **нет** | только метрические | нет | да | компоненты не двигать |

### 6.4. Особенности формата DSN (ограничения)

1. Не прописываются **диаметры отверстий** (TopoR ставит по умолчанию) — настроить перед Gerber/DXF.
2. Не передаются слои **маски и пасты**.
3. **Текст не передаётся**, только его охватывающий прямоугольник как **запрет трассировки**.
4. В именах компонентов не должно быть `'` и `"` (служебные символы).
Дополнительно (из разделов САПР): не передаётся фиксация компонентов (OrCad); pin/gate swap через DSN не передаётся (P-CAD); некоторые САПР (Proteus) берут из SES только проводники и переходы.

### 6.5. P-CAD 2000–2006

- Импорт: только **ASCII** `.pcb` (File > Save As → «ASCII Files (*.pcb)»). Экспорт: ASCII `.pcb` с указанием версии P-CAD. Можно через `.dsn/.ses`, но ASCII PCB полнее; через DSN **не передаётся функциональная эквивалентность контактов** (P-CAD её не сохраняет в DSN). Дуги: P-CAD до 2004 — кратные 0.1°.
- Цветовая схема «P-CAD 2006» в настройках.

### 6.6. Altium Designer

- Импорт: File > Save As → «Export P-CAD ASCII (*.pcb)» (сменить расширение .pcbdoc → .pcb), либо «Export Specctra Design File (*.dsn)» с настройками вкладки General. Контур платы — линиями/дугами на **Keep-out Layer**, не Room.

### 6.7. Cadence OrCad Layout

- Импорт: File > Export > Layout to SPECCTRA (`.max` → `.cct` переименовать в `.dsn`). Экспорт: File > Import > SPECCTRA to Layout с Original Layout File.
- Потери: фиксация компонентов; полигоны в посадочных местах отдельно от тела; Obstacle: Board outline → контуры (можно несколько + общий); Copper pour → только на опорных слоях; Copper area → передаётся (перезалить в TopoR); Anti-copper → не передаётся (трюк через Board outline + «Преобразовать в область металлизации» островка); Route keepout / Route-via keepout → запреты (Global layer → «все сигнальные слои»); Insertion outline, Detail, Free track → нет.
- Обратно не передаются: новые слои, изменение контура, изменения КП/ПО, полигоны и вырезы, матрица ПО (OrCad удаляет дубли; альтернатива — Free Via, которые TopoR видит как одноконтактные компоненты **FreePads**).
- Точность: **≤4 знака после запятой** у координат КП (5-й знак → ложные неразведённые цепи и потеря проводников при повторном DSN). Нет русских имён файлов и пробелов. Global Spacing → минимальный зазор; Conn Weight → минимальная ширина по группам цепей. Неподключённая КП → запрет трассировки на всех слоях диаметром КП (онлайн-DRC штрихи, финальная DRC чистая).

### 6.8. Mentor Graphics Expedition

- Импорт: File > Export > Design Data → группа `.hkp`; в 2007.8 бинарные — раскодировать `DataConvert.exe`. Экспорт: Файл > Экспорт > Expedition > Expedition 2005.

### 6.9. DipTrace

- Импорт: File > Export > P-CAD ASCII (`.pcb`) или Autorouter DSN. Экспорт: P-CAD `.pcb` или `.ses` (САПР DipTrace); импорт в DipTrace через File > Import > P-CAD ASCII / Autorouter SES. Проблема десятичного разделителя (Windows «,» vs «.» в .ses).

### 6.10. Pulsonix, Proteus ARES, Eagle, KiCad, CADint

- **Pulsonix**: Tools > Link to Specctra Routers > Specctra (Launch Router выкл.) → `.dsn`; обратно Load Specctra Results; координаты компонентов не читает.
- **Proteus ARES**: Tools > Auto Router > Export Design File → `.edf` (импорт как Specctra); обратно Import Session File; координаты не читает.
- **Eagle**: Файл > Импорт > Eagle BRD / Файл > Экспорт > Eagle > Eagle BRD; в 6.2 исправлены атрибуты корпусов и value.
- **KiCad**: `.brd` → Файл > Экспорт > Specctra DSN; обратно Файл > Импорт > Specctra Session (`.ses`).
- **CADint**: `.scl` → File > Export > Export Electra/Specctra AutoRouter (Generate & Launch, отменить запуск Electra) → `.dsn`; обратно `.ses` с САПР CADint.

### 6.11. Файлы для производства и отчёты

- **Gerber** (Файл > Файлы для производства > Gerber…, окно «Вывод Gerber (274X) файлов»): слева список файлов, справа слой и объекты слоя, назначаемые в файл; имя файла редактируется; **зеркальный вывод**, **смещение по осям**; «Создать файл»/«Удалить файл»/«Отметить»/«Конфигурации» (сохранить/загрузить/по умолчанию); **Формат…** — единицы **мм/мил**, формат чисел **«4.4»**, **«5.3»** или свой; «Создать файлы». Специальный слой **Board_outline** при экспорте в Gerber (6.2).
- **Drill** (Файл > Файлы для производства > Drill…, «Вывод файлов сверловки»): список файлов и содержимое; «Формат…» координат; «Создать файлы». Формат Excellon.
- **DXF** (Файл > Экспорт > DXF…): имя файла, **размер символов отверстий**, кнопка «Символы отверстий» — разные символы для разных диаметров; таблица символов выводится автоматически; многострочный текст (6.2).
- **BOM** (Файл > Экспорт > BOM…): атрибуты **Count, Footprint, Part Name, RefDes, Value**; далее, например, в «Компас».
- **ECO** (Файл > Инструменты > Создание ECO-файла для обратной синхронизации): переносит в `.eco` изменения, в частности переназначения эквивалентных контактов.
- **Печать** (Ctrl+P): область — текущий вид / вся рабочая область / выделенная («Выделить сейчас»); принтер; ориентация; масштаб — вписать / 1:1 / специальный (разбиение на страницы); цветовая схема (печать — ч/б), схема отображения, зеркальный вид; вкладка «Дополнительно» — исключить необязательные элементы (например, неразведённые связи).
- **Дизайн > Площадь металлизации** — общая площадь металлизации (копирование в буфер). **Дизайн > Сводная информация** — основные характеристики.

### 6.12. Синхронизация PCB-дизайна со схемой (с 6.3)

- **Прямая** (forward annotate, Инструменты > Синхронизация): перенос изменений из дизайна-источника **FSX_SCH** (свежий импорт из внешней САПР) в приёмник **FSX_PCB** (разведённый в TopoR) с сохранением разводки и параметров. Шаги: выбор источника → соответствия компонентов и цепей → редактирование списка ECO-команд («Выбор изменений») → «Выполнить» («Внесение изменений») → список команд обратной синхронизации → создание ECO-файла.
- **Обратная** (back annotate, Инструменты > Создание ECO-файла для обратной синхронизации…): только создание `.eco`.
- **Синхронизируемые объекты**: схемные компоненты (выводы, эквивалентность), посадочные места, стеки КП, компоненты (посадочные места, атрибуты), фрипады, монтажные отверстия, имена и состав цепей. **Не синхронизируются**: проводники, ПО, стек слоёв, области металлизации, запреты, надписи, ярлыки, детали на механических/документирующих слоях, дополнительные настройки.
- **Соответствия**: компоненты — по атрибуту **UniqueId** (кнопка «Изменить» генерирует новый и рвёт связь); если нет совпадений — по посадочному месту, координатам и RefDes (сценарий «промежуточной синхронизации по координатам»). Цепи — по имени, затем по составу. Контакты, монтажные отверстия — только по имени. Объекты источника без соответствия добавляются в приёмник. Ручная правка соответствий, фильтры и сортировка.
- Таблица команд: номер, текст, статус (**Отказ**/**Предупреждение**), номер команды-причины. **N-отказ** — ссылка на несуществующий объект (отмена добавления компонента/цепи, изменения посадочного места). **D-отказ** — дублирование имени (отмена переименования/удаления). Предупреждение — конфликт версий посадочного места/схемного компонента разрешается копией `DIP8_copy` / `СК1_copy`.
- Полный список ECO-команд и попадание в ECO-файл (да/нет): Согласовать UniqueId — нет; Удалить компонент — да; Удалить цепь — да; Удалить одиночный контакт — нет; Удалить монтажное отверстие — нет; Изменить стек КП — нет; Изменить стиль надписей — нет; Изменить посадочное место / схемный компонент / карту назначений контактов (неотключаемые) — нет; Переименовать компонент — да; Переименовать цепь — да; Изменить схемный компонент и/или посадочное место у компонента — нет; Изменить атрибуты — нет; Добавить компонент (посадочное место) — да; Добавить цепь — да; Добавить одиночный контакт — нет; Добавить монтажное отверстие — нет; Исключить контакт из цепи — да; Исключить монтажное отверстие из цепи — нет; **Переназначить цепи эквивалентных контактов** — да; Изменить цепь контакта — да; Изменить цепь монтажного отверстия — да; Добавить контакт в цепь — да; Добавить монтажное отверстие в цепь — да.
- Сценарий с **Delta Design**: схема → плата в DD → экспорт в TopoR (FSX_PCB) → разводка → изменения схемы в DD → экспорт (FSX_SCH) → синхронизация → FSX_Sync + ECO → применить ECO в DD.

## 7. Полный список кодов сообщений (раздел «Список сообщений об ошибках»)

Подстановки: `%N` — параметры. Типичная форма DRC: `%1 на слое '%2' между <A> и <B>: <факт> вместо <норма> <ед.>`. Для полноты приводятся все коды; группировка по классам объектов.

### 7.1. Нарушения DRC (4xxx) — выводятся процедурой DRC и онлайн-контролем

**Контакт (с цепью) против …**
- 4001 — контакта другой цепи

## 8. Глоссарий терминов TopoR

Примечание: файл `d05_glossary` в справке на самом деле — **«Предметный указатель»** (список ключевых слов без определений). Отдельного глоссария в справке нет; определения ниже собраны из текста соответствующих разделов.

| Термин (как в справке) | Определение |
|---|---|
| **Топологический трассировщик** | трассировщик, работающий с топологическим маршрутом проводника (с какой стороны каких препятствий), а не с его геометрией; без сетки и без преимущественных направлений слоёв |
| **Гибкая трассировка** | метод без жёсткой фиксации геометрии проложенных трасс; подвижность ранее проложенных проводников сохраняется при расчёте формы |
| **Топологический маршрут / путь** | последовательность препятствий, которые проводник огибает; задаётся при ручной прокладке, оптимизируется Refine |
| **Форма проводника** | геометрия, вычисляемая по маршруту (F5): Any-angle / С дугами / Под 45° |
| **Any-angle** | форма проводников ломаными под любым углом (ранее «без использования дуг») |
| **С дугами** | форма, где дуги вокруг препятствий чередуются с касательными отрезками |
| **Под 45°** | форма проводников под углами, кратными 45° (7.0); не отдельный способ прокладки |
| **Капельки** | переключатель на панели действий, меняющий флаг формы проводников для всей платы (хранится в дизайне) |
| **Расчёт формы проводников (F5)** | автопроцедура пересчёта геометрии по топологии |
| **Перекладка проводников / Refine (F6)** | автопроцедура оптимизации топологических путей (и, в подрежиме, слоя) проводников; удаляет избыточные ПО |
| **Подвижка (переходов / элементов) (F7)** | автопроцедура перемещения ПО (и компонентов) в оптимальные положения; три подрежима |
| **Freestyle (F8)** | режим перемещения компонентов, ПО и точек ветвления с автоматическим пересчётом формы и подталкиванием |
| **Подталкивание** | автоматический сдвиг соседних ПО/ветвлений/компонентов при перемещении объекта с соблюдением зазоров |
| **Точка ветвления** | точка, где проводник разветвляется (T-соединение); подвижный примитив в Freestyle |
| **Линия связи (netline)** | отрезок между парой ближайших примитивов двух компонент связности неразведённой цепи |
| **Целеуказатель** | штриховая линия до ближайшей точки неподсоединённого фрагмента, когда путь в текущем слое не найден |
| **Клинч** | пара проводников, взаимно блокирующих друг друга, не устранимая одиночной перекладкой любого из них |
| **Подрезка** | сужение проводника номинальной ширины до минимальной в узком месте; критерий оптимизации |
| **Минимальная / номинальная ширина** | ширина для узких мест и подхода к малым КП / желаемая ширина |
| **Минимальный / номинальный (желательный) зазор** | зазор для самых узких мест / зазор там, где можно раздвинуть проводники |
| **Ослабленный контроль зазоров (Weak check)** | режим автотрассировки, игнорирующий нарушения между контактами разных нефиксированных компонентов в расчёте на F7 |
| **Строгий контроль (Strict check)** | режим без таких послаблений |
| **Вариант (автотрассировки)** | сохранённое состояние разводки с параметрами длина/переходы/нарушения/подрезки; файл `.fsb` |
| **Уровень** | номер цикла перекладки цепей, на котором получен вариант |
| **мм/переход** | прирост длины на один убранный переход; эталон ≈25 мм/переход |
| **Таблица рекордов** | таблица вариантов на вкладке «Варианты» |
| **Фиксация** | запрет перемещения/изменения объекта (компонент, сегмент, ПО, полигон, змейка); F |
| **Гибкая фиксация** | фиксация топологии цепи (включая ПО) без фиксации геометрии; цепь не трассируется |
| **Выборочная трассировка** | автотрассировка части цепей с гибкой фиксацией остальных |
| **Дооптимизация** | продолжение оптимизации с сохранённого варианта («Продолжить») |
| **Переход, ПО, межслойный переход** | переходное отверстие; тип ПО: имя, диапазон слоёв, диаметры КП/отверстия, разрешение на КП |
| **Ряд / матрица переходов** | групповое создание ПО с заданными зазорами |
| **Избыточный переход** | ПО, не нужное для связности (5037); автоматически удаляется после автопроцедур |
| **Стек КП (СКП, падстек)** | набор деталей контактной площадки по слоям; типы сквозной/планарный/монтажное отверстие |
| **Деталь (КП)** | фигура площадки на одном слое или группе слоёв; также примитив на механическом/маска/паста слоях |
| **Точка привязки (КП)** | точка, к которой подводится проводник; КП может быть смещена относительно неё |
| **Finger pad** | прямоугольник со скруглёнными углами с радиусом = половине ширины |
| **Фрипад (FreePad)** | одноконтактный компонент (например, Free Via из OrCad) |
| **Монтажное отверстие** | тип стека КП; синхронизируемый объект |
| **Незадействованный / неподключённый контакт** | контакт без цепи; отдельный класс объектов в DRC |
| **Функционально эквивалентные контакты (ЭК)** | контакты, которые можно менять местами (pin swap); вентиль (В), эквивалентность вентилей (ЭВ) — gate swap |
| **Перемычка (П)** | в свойствах контактов — связь двух контактов перемычкой; при однослойной трассировке — проволочная перемычка (2 перехода) |
| **Опорный слой** | металлический слой-плоскость; цепи назначаются на него правилом |
| **Назначение цепей на слои** | правило, ограничивающее слои прокладки цепи (предупреждение 5047) |
| **Активный слой** | слой, с которого начинается поиск объектов под курсором; рисуется поверх; принимает новые объекты |
| **Запрет (трассировки / размещения)** | область-барьер: для проводников и/или ПО на выбранных слоях; для компонентов на сторонах |
| **Запрет металлизации** | барьер в DRC (в компоненте или свободный), отличный от запрета трассировки |
| **Область металлизации (полигон)** | заливаемая медная область с цепью, приоритетом, термобарьерами, штриховкой |
| **Выкусывание** | вырезание объектов других цепей из заливки с зазором |
| **Островок** | несвязанная часть залитой области; может удаляться по площади/неподключённости; «Преобразовать в область металлизации» |

| **Деталь на механическом слое** | линия/дуга/круг/окружность/прямоугольник/многоугольник на механическом слое |
| **Надпись / ярлык / стиль** | свободный текст / отображение атрибута компонента / шрифт+толщина+высота |

| **Трапеция (область змейки)** | область, в которую вписывается змейка; «узкая» при ширине < периода |
| **Застёгнутая пара проводников / застёжка / замок** | связанная пара проводников дифф. пары, ограниченная замками, перпендикулярными ближайшему сегменту |
| **Застегнуть / Расстегнуть** | объединить два проводника в застёгнутую пару / разъединить |
| **Фанаут** | ПО, соединённое с рядом стоящей планарной КП (BGA, питание/земля) |
| **BGA регулярная / нерегулярная** | контакты в узлах прямоугольной сетки / иное расположение |
| **Полигональная разводка** | преобразование проводников в области металлизации |
| **Авторазмещение** | силовой алгоритм + дихотомическое разбиение; удаляет разводку |
| **Область размещения** | прямоугольник для авторазмещения; редактируемый |
| **Online DRC (быстрая проверка зазоров)** | контроль на модели в редакторе; по умолчанию выключен |
| **DRC** | проверка по реальной геометрии: целостность, ширина, зазоры; допуск; drc.log; лимит 1000 |
| **Фильтр сообщений** | выбор категорий проверок редактора |
| **Фильтр выделения** | 12 флагов типов объектов, доступных для выделения |
| **Циклическое выделение (X)** | сегмент → проводник → цепь → сегмент |
| **Выделение окном** | слева направо — целиком, справа налево — частично |
| **Схема отображения / цветовая схема** | набор флагов видимости / набор цветов; предопределённые и пользовательские |
| **Отсоединить (U)** | отцепить проводники от компонента перед поворотом/сменой стороны |
| **Переворот** | «трёхмерная» операция: компонент и проводники на симметричный слой |
| **Синхронизация (прямая / обратная)** | перенос изменений схема→плата / плата→схема (ECO) |
| **UniqueId** | атрибут компонента для установления соответствий при синхронизации |

| **Файл-прототип** | исходный файл того же формата, используемый при экспорте для сохранения неиспользуемых TopoR данных |
| **Проект / документ / дизайн** | `.fsproj` / файл в проекте / плата или вариант (`.fsx`, `.fsb`) |
| **TopoR PCB (.fst)** | открытый XML-формат обмена, версия 1.2.0 |
| **Экспорт по прототипу** | см. файл-прототип |
| **Единицы** | мм или мил; переключение в окне управления видимостью |

## 9A. Приложение A — сводная модель данных TopoR (чек-лист сущностей и атрибутов для XrTopoR)

Собрано по всем разделам справки; это перечень того, что должно существовать в модели XrTopoR, чтобы покрыть описанное поведение.

### Дизайн (Design / Board)
- Единицы (мм | мил), точность 0.1 мкм.
- Стек слоёв: упорядоченный список слоёв {имя, тип, толщина, флаг «Учитывать при размещении» (для механических)}; группы слоёв.
- Типы слоёв: сигнальный, опорный, механический (верх/низ), документирующий, маска (Mask Top/Bottom), паста (Paste Top/Bottom), шелкография/сторона размещения.
- Контур платы (многоугольник/прямоугольник/с дугами) + вырезы в контуре (роль «Вырез в контуре платы»); толщина линии.
- Стеки КП, типы ПО, стили надписей, схемы отображения/цветов (пользовательские хранятся в файле схем, не в дизайне).
- Подрежим F5 (с дугами / без), флаг «капельки».
- Настройки редактирования (ярлыки), настройки подсоединения к углам (список стеков/контактов).
- Фильтр сообщений (категории), настройки DRC (объекты, допуск, отчёт, лимит).

### Стек КП (Padstack)
- Имя; тип: сквозной | планарный | монтажное отверстие; диаметр отверстия (для непланарных).
- Детали по классам слоёв (паста, маска, сигнальный, опорный) и по конкретным слоям; одна деталь на слой.
- Деталь: форма ∈ {круг(d, dx, dy), овал(d, вытягивание X, вытягивание Y, dx, dy), прямоугольник(w, h, dx, dy, тип углов: нет|скругление|срез, величина, custom-флаги по углам), многоугольник(вершины)}.
- Свойства термобарьера (угол, ширина спиц, ширина барьера, напрямую/через барьер).
- Разрешение подсоединения к углам (явное или авто по радиусу > w/2).

### Тип ПО (Via type)
- Имя; диапазон слоёв (от–до); диаметр КП (общий или по слоям, включая механические); диаметр отверстия; флаг «разрешён на КП».

### Компонент (Component)
- RefDes, PartName (обязательные атрибуты), прочие атрибуты, UniqueId.
- Посадочное место (footprint) + схемный компонент (part): контакты {имя, стек КП, координаты, угол, цепь, ЭК, В, ЭВ, П}.
- Сторона (Top/Bottom), положение, угол (произвольный), зафиксирован (bool).
- Ярлыки атрибутов {слой, координаты, угол, зеркальность, точка привязки, включён, стиль}.
- Очертания на механических слоях; полигоны/запреты в составе посадочного места («в компоненте»).
- Фрипады (одноконтактные), монтажные отверстия — отдельные классы.

### Цепь (Net)
- Имя; список контактов; группы (множественное членство); флаги: трассировать, зафиксирована, гибко зафиксирована; назначение на слои / на опорный слой; назначенные типы ПО.

### Проводник (Wire/Track) — модель TopoR
- Цепь, слой, топологический маршрут; производная геометрия: сегменты (прямые и дуги) с шириной каждого сегмента; точки ветвления; концы на примитивах (КП, ПО, полигон, сегмент, ветвление).
- Флаг фиксации по сегменту; «связующий подвижный проводник».
- Специальные подтипы: змейка (трапеция + параметры задержки), застёгнутый участок дифф. пары (с замками), перемычка (однослойный режим).

### Переход (Via)
- Тип ПО, цепь, координаты, фиксация, (гибкая фиксация через цепь).

### Область металлизации (Copper area)
- Цепь, слой, состояние (без заливки | залита | зафиксирована), контур (с дугами), приоритет, зазор (опционально), термобарьеры, удалять неподключённые островки, минимальная площадь островка, точность аппроксимации, штриховка (сплошная|сетка|диагональная, толщина линий, зазор между линиями), вырезы, островки (результат заливки).

### Запрет (Keepout)
- Роль: трассировки (цель: проводники | ПО | оба; слои) | размещения (сторона: верх | низ | обе); контур с дугами.

### Надпись (Text)
- Текст, слой (шелкография/сигнальные), угол, зеркальность, стиль {шрифт растровый, толщина линии, высота}, точка привязки, выравнивание.

### Деталь на механическом слое (Detail)
- Линия, дуга (центр/начало/конец, против часовой), круг (залитый), окружность, прямоугольник, многоугольник.

### Сигналы (High-speed)
- Сигнал {имя, источник(контакт), приёмник(контакт), кластер, связи по цепям}; кластер {источник, цепи, Zo}; ДС {два сигнала, допустимый разброс длин, Zo}; группы сигналов; Zo {имя, ширина по сигнальным слоям, значение Ом (информационно)}.
- Правила выравнивания в группе {группа, допуск, вкл}; взаимного {объект1, объект2?, константа, tolerance+, tolerance−, вкл}.
- Настройки поиска {max цепей в кластере, силовые цепи, min контактов силовой цепи, автосвязи, правила именования ДС (подстроки, приоритет, вкл)}.

### Правила
- Ширина {min, nom, слой/группа, объект}; зазор проводников {min, nom, слой/группа, объект1, объект2}; зазор компонентов {nom, слой/группа, объект1, объект2}; зазор до края {компоненты, проводники}; ПО по цепям; цепи опорных слоёв; цепи на слои. Порядок = приоритет.

### Автотрассировка (сессия)
- Набор трассируемых цепей; флаги вкладки «Настройки»; форма проводников; таблица вариантов {имя, длина, переходы, нарушения, подрезки, таймер, уровень, мм/переход}; текущий вариант; состояние (не запущена | идёт | остановлена).

### Проект
- `.fsproj`: разделы «Документы», «Варианты автотрассировки», папки, текущий файл, история.

## 9D. Приложение D — ответы FAQ, значимые для алгоритмов (выжимка)

- «Можно ли трассировать по сетке и ортогонально?» — автоматически нет (любой угол); вручную — привязка к сетке/углу.
- «Почему TopoR прокладывает несколько проводников между контактами, где помещается один, и сам показывает нарушение?» — потому что «TopoR всегда разводит все цепи»; если при заданных ширине/зазорах проводник не помещается и другого пути нет — проложит с нарушением. Проверять min/nom ширину и зазор.
- «Изменил ширину в правилах, перезапустил — ширина не изменилась» — дооптимизация варианта сохраняет старые ширины; нужна переразводка с нуля (удалить разводку).
- «Как быстро увеличить ширину всех проводников» — фильтр выделения только проводники → Ctrl+A → свойства → ширина.
- «Почему место есть, а DRC-нарушения создаются» — неточности расчёта формы у мелких частых планарных КП; nom зазор > min; сдвинуть объект / исправить и зафиксировать / добавить запрет.
- «Почему форма моих проводников меняется, можно ли запретить» — Freestyle пересчитывает форму без изменения пути; автопроцедуры с оптимизацией путей могут менять путь и слой; запрет — фиксация (F); расхождение проводников для увеличения зазора — через номинальный зазор.
- «Пересекаются два контакта одной цепи, ошибка 3004/5008 блокирует запуск» — зафиксировать оба компонента.
- «Полигоны» — залить до трассировки (непроходимый) или после устранения всех DRC (разрезаемый); перезаливать после перемещений внутри.
- «Двухстороннее авторазмещение» — нет, сторона не меняется.
- «Теряются ли дуги при импорте» — сохраняются до первого редактирования.
- «Теряются ли сигналы при экспорте» — сохраняются только для 1 двухконтактной цепи (ДС — 2 цепи).
- «Эквивалентные контакты» — только чтение из библиотеки; результат переназначения — в ECO.
- «Трассирует несколько часов и не останавливается» — оптимизация бесконечна; останавливать вручную по подсказке.

## 9E. Приложение E — эталонный сквозной сценарий (раздел «Пример проектирования», Z80)

1. Файл > Создать проект → имя. Файл > Импорт → формат, файл `Z80-routed.pcb` → Импорт → Закрыть → дизайн в проекте и в редакторе; при желании удалить разводку.
2. F4: Слои — очертания компонентов на шелкографии → флаги «Учитывать при размещении». Группы цепей — группа Power {GND, VCC}. Правила > Ширина проводников: удалить текущие; все цепи 0.25 мм; Power 0.5 мм; min = nom. Правила > Зазор между проводниками: min/nom для всех цепей. Применить, закрыть.
3. Автотрассировка: выбрать цепи (можно сначала критичные), Настройки при необходимости, Запустить. «На небольших платах для получения приемлемого варианта достаточно нескольких минут». Остановить → выбрать вариант → Открыть в редакторе. Строка состояния: 6936.35 мм, 90 переходов, 0 нарушений; нарушения — в окне сообщений с координатами и слоем, клик — мигающая подсветка.
4. Редактирование: заузить толстый проводник (W) для устранения зазора; F5 с дугами — нарушений нет; устранить «клинчи» вручную (пара проводников, не разрешимая одиночной перекладкой); итог 666 см / 4 перехода против 775 см / 20 у Protel DXP.
5. DRC → при нуле — информационное окно; иначе сообщения и белые окружности.
6. Экспорт в исходную САПР мастером экспорта или выпуск файлов производства.

## 10. Что это значит для XrTopoR — 20 ключевых поведений, которые нужно воспроизвести

1. **Топология первична, геометрия вторична.** Внутреннее представление проводника — топологический маршрут (последовательность обходимых препятствий / сторон), а не полилиния. Геометрия всегда производная и пересчитывается (F5). Ручная прокладка задаёт только маршрут; касания и чётные пересечения не ошибки. Нужны ровно два класса топологических ошибок: нечётное пересечение проводников одного слоя и проход через центр чужого контакта.

2. **Три генератора формы из одной топологии**: Any-angle (ломаные), С дугами (дуги вокруг препятствий радиуса r+зазор+w/2 + касательные), Под 45° (пост-обработка). Переключение в любой момент без изменения маршрута. Подрежим F5 и флаг «капельки» хранятся в дизайне.

3. **Правила с парой значений (min/nom) и приоритетом по номеру.** Ширина: min используется только в узких местах и при подходе к малым КП; целевая функция минимизирует число заужённых сегментов («подрезок»). Зазор: nom используется везде, где есть место, min — только между контактами/в узких местах. Правила — по цепи/группе/сигналу/группе сигналов × слой/группа слоёв; больший номер выигрывает.

4. **Автотрассировка = «100% сразу, затем бесконечная оптимизация».** Начальная полная разводка с нарушениями → циклы «перекладки цепей» (Уровень). Нет критерия автоматической остановки — только подсказка «Поиск вариантов целесообразно остановить» при стагнации; рекомендация пользователю — Уровень 5–10.

5. **Таблица вариантов как Парето-фронт** по (нарушения, переходы, длина, подрезки): замещение при доминировании по всем, добавление при «не хуже» по какому-либо; первый вариант после первого цикла или 20 с; сортировка по нарушениям, затем длине; столбец мм/переход (эталон 25 мм/переход); файлы `name_LLL-VVV[w|s][a].fsb`; «Продолжить» с варианта; «Добавить в проект»; длина в таблице — несглаженная (+10–15%).

6. **ПО во время оптимизации — не точка, а фрагмент проводника между парой пересечений** (отрезок между слоями, который можно скользить). Это ключевой трюк гибкости; следствие — недооценка размеров ПО и нарушения в скоплениях после «материализации» ПО в редакторе. Нужно воспроизвести и трюк, и честно документировать следствие.

7. **Трассировщик двигает незафиксированные компоненты** и не ограничивает число проводников между ними (ожидая F7), особенно при «Ослабленный контроль зазоров». Фиксация компонента (F) — единственный способ запретить. Сторона установки и поворот не меняются автоматически.

8. **Два уровня фиксации проводников**: жёсткая (геометрия сегмента + концевые ПО, с правилами наследования из 4.7, включая «связующий подвижный проводник» при перемещении компонента) и **гибкая** (только топология + положения ПО; цепь исключается из трассировки и из Refine). Фиксация превращает топологический конфликт в предупреждение → легальный способ соединить цепи.

9. **Три автопроцедуры с подрежимами**: F5 (форма: без дуг/с дугами), F6 Refine (пути; со сменой слоя только между сквозными КП/ПО или без; автоудаление избыточных ПО; не трогает гибко зафиксированные), F7 подвижка (ПО без перекладки / ПО с перекладкой / ПО + компоненты с перекладкой; не работает внутри залитых полигонов; учитывает очертания на слоях «Учитывать при размещении»). Подрежим F5 — в файле, F6/F7 — в сеансе.

10. **Freestyle** — перемещение компонентов, ПО и точек ветвления с мгновенным пересчётом формы и тремя режимами подталкивания (нет / ПО+ветвления / компоненты+ПО+ветвления). Форма проводников в этом режиме не редактируется вручную; топологический путь не меняется.

11. **Ручная прокладка с автопоиском пути**: цель — ближайшая пара примитивов компонент связности; автопоиск бесконфликтного пути в текущем слое (штрих-пунктир), принятие `;`, смена цели `Q` (если ближе), целеуказатель при отсутствии пути, `L` → ПО автоматически, `Backspace` — шаг назад, окончание на ПО и ПО до опорного слоя.

12. **Подсоединение к КП**: к точке привязки; к углам только для скруглённых/срезанных прямоугольников с радиусом > w/2 (или явно разрешённых стеков/контактов); прямое соединение соседних планарных контактов одного компонента по флагу; via-in-pad только по флагу типа ПО; «не дотягивать до точки привязки полигонального контакта»; термобарьеры с целевыми 4 спицами.

13. **Модель объектов DRC** различает: контакт с цепью / незадействованный; ПО; проводник; область металлизации подключённая/неподключённая × в компоненте/свободная; запрет металлизации (в компоненте/свободный); запрет трассировки (проводники/ПО/оба, по слоям); запрет размещения (стороны) и запрет размещения переходов; надпись; ярлык; контур платы; змейка; проводник дифф. сигнала. Коды 4001–4107 и 5003–5057 — готовая спецификация сообщений. DRC: целостность, ширина, зазоры, допуск, лимит 1000, drc.log, белые окружности.

14. **Полигоны**: три состояния (без заливки / залита / зафиксирована), выкусывание с зазором max(зазор цепи полигона, зазор цепи объекта), приоритет (больший выкусывается из меньшего; при равенстве — меньшая площадь из большей), островки (неподключённые, минимальная площадь), штриховка (сплошная/сетка/диагональная), точность аппроксимации, термобарьеры; залитый полигон для трассировщика — препятствие без ПО чужих цепей; «Удалить заливку и восстановить проводники».

15. **Дифференциальные пары как «застёжка-молния»**: застёгнутые участки с замками, перпендикулярными ближайшему сегменту; требования к застёгиванию (один слой, ширины по Zo, длина ≥ 3×(2w+gap)); смена слоя = застёжка + пара ПО + застёжка; «Поменять цепи местами»; восстановление пар после round-trip; автотрассировка дифф. сигналов с последующим «Застегнуть все».

16. **Сигналы/кластеры/High-speed**: сигнал = источник→приёмник; кластер через пассивные компоненты с исключением силовых цепей; автопоиск дифф. пар по правилам именования (подстроки в одной позиции) и шин по индексу; Zo как таблица ширин по слоям (Ом не используется); правила выравнивания в группе (допуск в пс/нс) и взаимного (`−t⁻ ≤ D1−D2−c ≤ t⁺`); змейки в трапециях с точностью 50 нм, зазор по умолчанию 2w, минимальная ширина области 1.5w, узкие области без дуг; «Создать змейки» автоматически.

17. **Фанауты и BGA**: Fanout до трассировки — от центра по квадрантам для регулярных BGA, отдельный алгоритм для нерегулярных и повёрнутых; ~1500 ПО/с как ориентир производительности. Автотрассировка BGA использует минимальный тип ПО и два правила (внешний слой/остальные), только сетка с поворотом кратным 90°.

18. **Однослойный режим** с перемычками (переход = полперемычки, перемычки прямые, нет фиксированных длин) и «Ослабленный контроль» как штатный сценарий; выбор варианта с минимумом переходов; 5–6 итераций «трассировка → F7 с компонентами → F7 с ПО → ручная правка → гибкая фиксация».

19. **Форматы и точность**: 0.1 мкм / 4 десятичных знака в мм; TopoR PCB `.fst` (XML 1.2.0) как основной обменный формат — XrTopoR должен читать/писать его совместимо; `.fsb` как сериализация варианта; экспорт «только используемые данные» + экспорт по прототипу; DSN без диаметров отверстий/маски/пасты/текста; SES с САПР-специфичными диалектами (кавычки, CCTVIA, единицы, дуги только для DipTrace, координаты компонентов не читают Altium/Proteus/Pulsonix); Gerber 274X с форматами 4.4/5.3 и слоем Board_outline; Drill Excellon; DXF с символами отверстий; BOM (Count, Footprint, Part Name, RefDes, Value); ECO.

20. **Авторазмещение и синхронизация** как второстепенные, но определённые алгоритмы: силовой алгоритм + дихотомическое разбиение с областями, пропорциональными площадям, с запоминанием лучшего по длине, удалением всей разводки и без смены стороны/поворота; синхронизация по UniqueId → (посадочное место, координаты, RefDes) → имя/состав цепи, с таблицей ECO-команд, N-/D-отказами и копиями `_copy` при конфликте посадочных мест.

### Дополнительные неочевидные детали, которые легко упустить

- Кнопка запуска автотрассировки блокируется ровно четырьмя условиями (нет цепей; лицензия по слоям; пересечение контактов; пересечение проводников в нетрассируемых цепях) — сообщается первое.
- При запуске удаляется разводка всех трассируемых нефиксированных цепей, кроме случая «Продолжить трассировку с текущей конфигурации»; «Удалить разводку» из меню удаляет и зафиксированные.
- Дооптимизация варианта сохраняет старые ширины (включая ручные), переразводка с нуля берёт ширины из правил.
- Форма проводников при импорте с дугами сохраняется до первого редактирования.
- Фиксация проводников и ПО не действует «в режиме размещения».
- Выделение окном: направление определяет полное/частичное включение.
- Активный слой рисуется поверх и принимает новые объекты; клавиши 1–9/0.
- Кнопка «По умолчанию» на вкладке «Настройки» автотрассировки выключает **все** флаги; «Переназначать функционально эквивалентные контакты» по умолчанию выключен; Online DRC по умолчанию выключен; лимит ошибок DRC 1000; змейка зазор 2w; радиус угла > w/2; термобарьер 4 спицы.
- Запись в сообщениях о невыполненном правиле выравнивания — в пикосекундах, первой указывается более короткая цепь.
